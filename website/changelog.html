0.1.0 — TBD

First public release.

  • Sessions sidebar with per-session bell counters and notifications mute.
  • Recursive horizontal / vertical splits with drag-resize and persistence.
  • Tab strip with auto-derived titles (project name → live OSC → cwd basename).
  • Bell Feed popover with click-to-jump and system notifications.
  • Drag-and-drop of file paths into a terminal with shell-quoted insertion.
  • Multi-line paste confirmation sheet.
  • Cmd-W busy-tab confirmation when a foreground process is running.
  • Auto-close on shell exit; close cascades through pane and session.
  • Sparkle auto-update wired to appcast.xml.
