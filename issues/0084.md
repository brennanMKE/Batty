## Description

Write the **Tabs** section of Batty's user Help: `Batty/Help/04-tabs.md`. Tabs are the horizontal strips of named terminals inside each pane.

Depends on `#0080` (Help window bootstrap).

## What `04-tabs.md` covers

### What a tab is

A single terminal (running shell + scrollback) within a pane. A pane always has at least one tab. The tab strip across the top of the pane shows every tab as a chip; the active tab's chip is highlighted.

### Creating a tab

- **`Cmd-T`** in the focused pane.
- **`+`** button at the right end of the tab strip.
- New tabs inherit the **working directory** of the previously active tab in the same pane.

### Switching tabs

- Click a chip.
- **`Cmd-1` … `Cmd-9`** to select by position.
- **`Cmd-Shift-[` / `Cmd-Shift-]`** for previous / next.

### Reordering tabs

Drag a chip left or right within the same tab strip. Cross-pane drag isn't supported in v1.

### Tab titles

By default, the chip shows a smart short label:

1. If you've renamed the tab, that name (highest priority).
2. The shell's title with the `user@host:` prefix stripped and the path prettified (e.g. `~/Developer/Batty` → `Batty`).
3. The current working directory's basename when the shell hasn't published a title.
4. Generic `Tab N` fallback.

Tabs running a known TUI (Claude Code, vim, htop, …) eventually display the app's display name (per `#0073`, once the writer signal lands).

### Renaming a tab

Right-click the chip → **Rename**. The current shell-emitted title appears as a placeholder hint, but the field starts empty — submitting an empty value clears the override and the chip returns to auto-titling. Submitting any non-empty value pins that name regardless of what the shell says.

You can also right-click → **Reset Title** to clear an existing override.

### Closing a tab

- **`Cmd-W`**.
- Click the chip's `×` (visible on hover and on the active tab).
- Type `exit` (or Ctrl-D at a bare prompt) in the shell — the tab closes when the shell exits (per `#0059`).

If the closed tab was the last in its pane, the pane closes. If it was the last pane in the session, the session closes. If it was the last session, the window closes and Batty quits.

### Context menu

Right-clicking a chip exposes: Rename, Reset Title, Duplicate Tab, Close Tab, Close Other Tabs.

### Unseen bells

A small accent-colored dot appears on a chip when a `\a` bell rings in that tab while you're looking somewhere else. The dot clears when you visit the tab (per `#0069`).
