## Description

End of M1. Wire up the minimum end-to-end app: launch Batty, see a working shell prompt rendered by libghostty inside a single Pane in a single Session in a single Window. No sidebar UI yet (M2), no tabs (M3), no splits (M4) — just a real Terminal Session you can type into.

**Acceptance criteria:**
- `ContentView` (or its successor) renders a single `TerminalSurfaceView` filling the window.
- Cmd-N opens a new window with its own surface.
- Typing reaches the shell; the shell's output renders correctly.
- Cmd-Q quits cleanly (surface destroyed via `dismantleNSView`).
- Window can be resized without blurring or clipping rendering (sanity-check that #0007 sizing is correct).
- This is the canonical "Hello, surface" milestone (PRD §9 M1).

## Notes

- The placeholder `Image(systemName: "globe")` ContentView from the Xcode template should be deleted in this issue.
- Don't introduce Session/Pane/Tab UI hierarchy yet — just enough scaffolding to put one surface on screen. Sidebar arrives in #0010.
- If this issue uncovers SwiftUI ↔ NSView lifecycle bugs, file follow-ups; don't try to solve general lifecycle problems here.
