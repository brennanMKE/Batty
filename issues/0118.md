## Description

Tier 3 localization target. Italy is a steady Apple market with a meaningful macOS user base; Italian is standard in Apple's localized-app set.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `it` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Italiano shows the full UI translated.
- Visual sweep for string-length expansion (~10–20% longer than English).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Terminology: "scheda" (tab), "sessione" (session), "riquadro" or "pannello" (pane). Confirm against Terminal.app for parity.
- Sparkle ships Italian strings.

## Root cause

The `it` locale had no entries in `Batty/Localizable.xcstrings` after the
#0107 foundation pass. Italian users would have seen English fallthrough
for every catalog-driven string when running with Language & Region set
to Italiano.

## Fix

Populated `it` for every key currently in the catalog:

- `Batty` → `Batty` (brand kept in Latin script)
- `Quit Batty?` → `Uscire da Batty?`
- `Quit` → `Esci`
- `Cancel` → `Annulla`
- `Paste %lld lines?` → `Incollare %lld riga?` / `Incollare %lld righe?` (plural one/other)
- `There %lld open terminal(s).` → `C'è %lld terminale aperto.` / `Ci sono %lld terminali aperti.` (plural one/other, with predicate agreement)
- `%lld unseen bell event(s)` → `%lld evento campanella non visualizzato` / `%lld eventi campanella non visualizzati` (plural one/other)

Apple's macOS Italian house style used throughout: infinitive button
verbs (`Esci`, `Annulla`), the verb-noun-question idiom for confirmation
titles (`Uscire da Batty?`), and `Incollare` rather than `Incolla` for
the destructive-action prompt. `%lld` format specifiers preserved.

## Files changed

- `Batty/Localizable.xcstrings` — added the `it` localization branch under each of the seven keys, with one/other plural variants on the three pluralized keys.

## Gotchas

- Translations are LLM-authored, not native-speaker reviewed. The acceptance criterion "reviewed by a native speaker" is still pending; the runtime visual sweep under `-AppleLanguages '(it)'` is also still on the user's sign-off list.
- "campanella" was chosen for "bell" to match Apple's macOS notification idiom; "campana" is also valid but less idiomatic for the OS sound-event sense.
- The initial subagent for this issue produced the catalog edits but its commit step failed due to a transient API outage. The orchestrator verified the partial state, ran the build, and made the code commit (`03af29f`) directly. Both translations and process are consistent with the per-language pattern used for #0108–#0117.
