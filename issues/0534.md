## Description

#0533 appended `ProjectSymbol.music` (`music.note`), so `ProjectSymbol.allCases` now has 37 cases (`BattyKit/Sources/BattyKit/Model/ProjectSymbol.swift`, `case folder` … `case music`). The #0533 reviewer noted that two places still say 36. A `git grep` of `issue/0533` (excluding `issues/`) found these two and no others:

- `BattyKit/Sources/BattyKit/Resources/SFSymbolNames.txt:19`, header comment: `# 36 Project symbols are added at load whether or not they appear here.`
- `Concepts.md:46`, Project **Contains** bullet: `a symbol (one of 36 curated SF Symbols, \`ProjectSymbol\`; ...)`

## Fix

Change `36` to `37` on both lines. Both are comments or docs, so behavior is unchanged. Better still, drop the number from the `SFSymbolNames.txt` comment (for example "The curated Project symbols are added at load…") so the next added symbol doesn't make it stale again. Keep the count in `Concepts.md` only if it stays accurate.

Verification: `./build.sh` (the resource file is bundled), then `git grep -nE "\b36\b" -- Concepts.md BattyKit/Sources/BattyKit/Resources/SFSymbolNames.txt` returns nothing about symbols.
