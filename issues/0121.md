## Description

Tier 3 localization target. Turkey has a growing developer market and a meaningful Apple install base. Turkish is standard in Apple's localized-app set.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `tr` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Türkçe shows the full UI translated.
- Visual sweep for string-length expansion (~10–20% longer than English; Turkish agglutinative suffixes can produce long single words in technical labels).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Watch for the **dotted-I vs dotless-ı** case-folding gotcha — Turkish locale is the classic case where `String.lowercased()` without `locale: .init(identifier: "tr")` produces wrong results. Not relevant to the static translation strings themselves, but worth a code audit if any user-facing string in Batty is produced by case-folding runtime data.
- Sparkle ships Turkish strings.
