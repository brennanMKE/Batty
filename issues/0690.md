## Description

Child of #0689, first in order. User decision A (2026-11-19): "No web view. Remove the Web Preview Pane, `batty server preview`, its Setting and WebKit use. Agents use whatever webdriver the developer tells them about (e.g. `safaridriver`)." Today #0649's `web-preview` Pane kind and its CLI and Settings entry points are on `main` behind the `serverPane` flag (Beta only).

## Expected behavior

- No `web-preview` Pane kind can be created. Remove the case if nothing decodes it; if anything stored can still carry the raw value, decode it as unknown and drop it (the plan checks which).
- Delete the files above and every reference; `git grep -n "import WebKit"` finds nothing in `BattyKit/Sources` or `Batty/`. Remove WebKit from any link settings.
- Remove `server preview` and its XPC verb and MCP tool. `server serve --open` opens the served URL in the default browser (`NSWorkspace.shared.open`). Remove `ServedSiteOpenTarget` and its Settings row; leave the stale defaults key unread.
- Remove the Server Pane's "Open in Batty" button (the Server Pane itself goes in #0691).
- `docs/design/web-preview-pane.md` gets a status line: "**Superseded** by #0690 (user decision 2026-11-19: no web view)". `docs/pane-kinds.md`, `docs/feature-flags.md`, `Concepts.md` (Web Preview Pane entry removed) and `PRD.md` (line 365) stop describing the Pane.

## Acceptance criteria

1. `batty capabilities --json` (Beta) lists no `server preview` verb; `batty server preview` is an unknown subcommand.
2. `git grep -n -i "webpreview\|web-preview\|WKWebView"` finds nothing outside `issues/`, the superseded design doc and retired-flag history.
3. `./build.sh`, `./build.sh unit` and `./build.sh ui-typecheck` pass; deleted tests are listed in the resolution.
4. A fresh install shows nothing new: no Settings row and no Pane kind replaces what was removed.
