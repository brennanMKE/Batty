## Description

> **Edited 2026-11-19 (#0689, user decisions A-E).** The Server Pane and Web Preview Pane no longer ship (#0690, #0691). Wherever this issue says "Server and Web Preview Panes", read: the toolbar **Servers** list, `batty server share|start|list|stop|restart|unshare|serve`, the PhotonHTTP static server and its `GET /_batty/status` API (#0693), and opt-in tailnet sharing (#0694). Setup is offered only in Settings → Advanced → AI Agents (no prompt, rescoped #0666). Add **webdriver guidance** (decision A): Batty has no in-app browser; to look at or test a page an agent uses whatever webdriver the developer has told it about (for example `safaridriver`, after the developer runs `safaridriver --enable` once), against the localhost or tailnet URL from `batty server list`. Help, the skill and the workflow doc say this; Batty never launches a browser automation tool itself. Follows `AGENTS.md`, "Top design goal: progressive disclosure": document features, don't push them.


Child of #0660, last in order. Once #0661–#0670 land, the user-facing and agent-facing text must say what 1.5.0 does: Batty tells an agent it is in Batty, registers its MCP server after one prompt, keeps it current, and lets the agent open Tabs and Panes that run commands and report their exit status. Today the docs call all of this "Beta only" and list Tab creation and waiting as missing.

### Current state

- In-app Help has no page for agents, Server Panes or Web Preview Panes (`BattyKit/Sources/BattyKit/Help/01-overview.md` … `11-backgrounds.md`).
- `.claude/skills/batty-cli/SKILL.md`: §10 is headed "Dev servers (Beta only)" (line 293) and says Prod has no `server` "until 1.5.0"; §9 describes `agent install` without the hook, Codex registration or the global-instructions prompt (#0664).
- `docs/batty-cli-agent-workflows.md`: section titles "(Beta only until 1.5.0)" (lines 457, 477); "Current limitations relevant to agents" says there is no verb for "creating a Tab" or "waiting for process state" (lines 546-548).
- Help page and SKILL.md: a short "Share a page from your project" workflow (as in #0683): write static files into a project folder, `batty server serve <dir>`, give the user the localhost URL from `server list`, and only if the user asks, share on the tailnet (#0694) and give the tailnet URL; stop the server when done.
- `docs/batty-cli-design.md`: `agent`/`mcp`/`server` described as flag-gated (§1.1); `tab new` listed as proposed (§2 A); `read` under "Advanced" with no recorded decision.
- `website/changelog.html` ends at 1.4.0 (line 19); there is no 1.5.0 entry or agent page.
- `PRD.md` and `Concepts.md` name Server Pane, Web Preview Pane and `batty mcp` (#0646) but not the setup offer, `agent context` or `tab new`.

- Website: a 1.5.0 changelog entry (written at release time) and an agent-integration section on the site, deployed per the website deploy process.
