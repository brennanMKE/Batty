# 0663 — The Claude Code plugin `agent install` stages has no SessionStart hook, so Claude Code learns it is in Batty only if it reads a note

## Description

Child of #0660. Claude Code plugins can declare a `SessionStart` hook whose standard output is added to the session's context. The `batty` (or `batty-beta`) plugin that `agent install` stages should run `batty agent context` (#0661) at session start, so a Claude Code session started in a Batty Pane knows it is in Batty, and which Pane, before its first turn, with no instruction file and without the agent running `env`.

### Current state

- `AgentGuidanceInstaller.stageMarketplace` (`BattyKit/Sources/BattyCLICore/AgentGuidanceInstaller.swift:358-386`) writes `.claude-plugin/marketplace.json`, the plugin's `.claude-plugin/plugin.json`, `.mcp.json` (the `mcp` server, absolute path to the bundled CLI, `identity.cliExecutablePath`) and `skills/batty-cli/SKILL.md`. No `hooks/hooks.json`.
- The plan then runs `claude plugin marketplace add <dir>` and `claude plugin install <plugin>@<marketplace>` (`AgentGuidanceInstaller.swift:237-249`).
- The user's hand-written `~/.claude/CLAUDE.md` section asks the agent to run `env | grep '^BATTY'` at session start. A hook makes that step unnecessary.

## Expected behavior

- `stageMarketplace` also writes `hooks/hooks.json` in the plugin directory with one `SessionStart` command hook: `"<identity.cliExecutablePath>" agent context`. Absolute path, as `.mcp.json` does, so it works without `batty` on `PATH`.
- Outside Batty the hook prints nothing (#0661), so it adds nothing to the context.
- The hook never fails or delays session start: `agent context` reads only the environment and always exits 0.
- Re-installing replaces the staged plugin directory as today, so the hook updates with the app.

## Acceptance criteria

1. `AgentGuidanceInstallerTests` asserts the staged plugin contains `hooks/hooks.json` with exactly that command and the `SessionStart` event, for both the Prod and Beta identity.
2. Manual (user checklist): after `batty-beta agent install`, a new Claude Code session in a Batty Pane, asked "where are you running?", answers with its Pane id without running a tool; the same in Terminal.app shows no Batty note.

## Open questions

1. **Hook schema.** The planner must check the current Claude Code plugin hook format (`hooks/hooks.json`, `{"hooks": {"SessionStart": [{"hooks": [{"type": "command", "command": …}]}]}}`) against Claude Code's docs at plan time, and whether a `matcher` (`startup`, `resume`, `clear`, `compact`) is needed. Recommended: no matcher, so context returns after `/clear` and compaction.
2. **Other hosts.** Codex and OpenCode have no equivalent wired here. Recommended: rely on the MCP `instructions` (#0662) and the global note (#0664) for them.
