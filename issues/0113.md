## Description

Tier 2 localization target. Latin American Spanish — covers Mexico, Argentina, Colombia, Chile, and the rest of Spanish-speaking Latin America (the largest combined Spanish-speaking population by far).

Depends on `#0107`. Pairs with `#0112` (European Spanish). Filed as a distinct issue because tech vocabulary diverges enough — particularly around computer terms — that a single neutral `es` reads awkwardly on one side.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `es-419` translation, reviewed by a native LatAm Spanish speaker.
- Launching with macOS Language & Region set to Español (Latinoamérica) shows the full UI translated.
- Visual sweep for string-length expansion (similar to `es`, ~15–20%).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Use "ustedes" / "tú" conventions — "vosotros" is rarely used outside Spain.
- Terminology: "computadora" (not "ordenador"), "carpeta" (folder), "pestaña" (tab) is common in both regions. Confirm against Terminal.app's LatAm Spanish translations.
- If a translator is unavailable for both `es` and `es-419` at the same time, ship the available one first and leave the other open; macOS falls back gracefully from `es-MX` / `es-AR` to whichever `es*` is present.
- Sparkle's single `es` covers both regions for update prompts.
