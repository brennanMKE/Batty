# 0151 — Add SF Symbols to menu items across View, Session, Theme, Pane, and Tab menus

| | |
|---|---|
| **Status** | open |
| **Module** | App |

| **First seen** | 2026-05-20 |

## Description

Batty's menus (View, Session, Theme, Pane, Tab) lack SF Symbol icons on their items. Xcode and other native macOS apps show symbols in front of key menu items to aid visual scanning and reinforce the action's meaning. Adding symbols to Batty's menus would improve discoverability and give the app a more polished, native feel.

## Expected behavior

The following menus have an SF Symbol on each item where one is appropriate. Suggested mappings (open to revision):

**Session menu**
- New Session — `plus.square`
- Rename Session — `pencil`
- Close Session — `xmark.square`

**View menu**
- Toggle Sidebar — `sidebar.left`
- Bell Feed — `bell`
- Enter Full Screen — `arrow.up.left.and.arrow.down.right`

**Theme menu**
- Global theme picker item — `paintbrush`
- Session-local theme picker item — `paintbrush.pointed`

**Pane menu**
- Split Horizontally — `rectangle.split.2x1`
- Split Vertically — `rectangle.split.1x2`
- Close Pane — `xmark.rectangle`
- Choose Layout — `rectangle.3.group`

**Tab menu**
- New Tab — `plus`
- Close Tab — `xmark`
- Next Tab — `chevron.right`
- Previous Tab — `chevron.left`

## Actual behavior

No SF Symbols appear on any menu items in these sections.

## Notes

- In SwiftUI `Commands`, symbols are added with `.image(systemName:)` on the `Button` label or by using `Label("Title", systemImage: "symbol.name")` in a `CommandGroup`.
- The exact symbol choice for each item can be refined during implementation — the list above is a starting point. Prefer symbols that Apple itself uses for the same concept (e.g. `sidebar.left` is the standard symbol for sidebar toggle in macOS apps).
- Related to #0150 (which specifically calls for a bolt symbol on "Open Quickly…").
