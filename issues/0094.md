## Description

UI regression tests for the full lifecycle of sessions, tabs, and panes — creation, renaming, closing with cascade behavior, the previous-sibling-selected-on-close rule (`#0067`), the quit-on-last-session behavior (`#0055`/`#0067`), and the auto-clear of orphaned bell-feed entries (`#0071`).

Depends on `#0091` (UI test harness bootstrap).

## What this issue ships

A `LifecycleTests` UI test class. Builds on the harness from `#0091`.

### Sessions

1. `sidebarPlusButton_createsSession` — click the sidebar's `+` button, assert a new session row appears.
2. `cmdN_createsSession` — keyboard equivalent.
3. `newSession_inheritsFocusedPaneCWD` — `cd` into a known directory, press `Cmd-N`, assert the new session's prompt is in that directory. Use a sentinel: `pwd > /tmp/...`.
4. `cachedSessionName_appliesOnCWDMatch` — rename a session to "Foo" in `/tmp/foo`. Create a new session in `/tmp/foo`. Assert the new session is named "Foo" automatically (per `#0058`).
5. `rightClickRename_pinsTitle` — rename via context menu, then `cd` to a directory that would auto-name to something else. Assert the title stays as the user's rename. (Pertinent to `#0089` once it lands; for now just verify `renameSession` writes are stable.)
6. `closeSession_selectsPreviousSibling` — open Sessions 1/2/3, select Session 3, close Session 3 via right-click. Assert Session 2 is now selected (per `#0067`).
7. `closeLastSession_quitsApp` — close the only session via the cascade. Assert app terminates without prompts.

### Tabs

8. `cmdT_createsTab` — assert a new chip appears.
9. `newTab_inheritsCWD` — `cd` somewhere, `Cmd-T`, sentinel that `pwd` in the new tab is the same.
10. `cmdW_closesTab` — covered in `#0093` but re-asserted here as cascade unit.
11. `closeLastTabInPane_removesPane` — open a horizontal split, close all tabs in one pane via `Cmd-W`. Assert the pane collapses and the surviving pane fills the space.
12. `closeLastPaneInSession_removesSession` — single session, single split, close all tabs in both panes. Assert the session is removed (and the previous-sibling rule kicks in if other sessions exist).
13. `chipReorderViaDrag` — drag a chip from position 1 to position 3, assert the order changed.
14. `chipContextMenu_renameAndResetTitle` — right-click → Rename "Logs", chip says "Logs". Right-click → Reset Title, chip returns to auto-resolved name.

### Panes

15. `cmdD_splits_andNewPaneInheritsCWD` — `cd` somewhere, `Cmd-D`, assert the new pane's tab is in the same directory.
16. `cmdShiftD_splitsVertically` — orientation check.
17. `closingPaneInheritsRemainingSpace` — split, close one half, the other half fills.
18. `dividerDragResizesPanes` — drag the divider, assert both panes' frames updated.

### Shell-exit auto-close (#0059)

19. `shellExit_closesTabAutomatically` — type `exit` and Enter in a tab, assert the tab closes within ~1s.
20. `shellExitOnLastTab_cascadesThroughClose` — single tab, `exit`, assert session and (if last) app terminate.

### Bell-feed cleanup on close (#0071)

21. `closingSessionWithBells_clearsFeedEntries` — open Session 2, ring a bell (`printf '\a'`), close Session 2 via right-click. Open the Bell Feed popover; assert it has no entries pointing at the now-gone tab.

## Acceptance criteria

- All 21 tests pass on the current build.
- A regression that breaks the previous-sibling rule (`#0067`) fails test 6.
- A regression that brings back the "recreate default session" behavior (`#0055`) fails test 7.
- A regression that fails to cascade tabs → panes → sessions (the cascade in `closeTab`) fails tests 11, 12, 20.
- A regression in shell-exit auto-close (`#0059`) fails tests 19, 20.
- A regression in bell-feed cleanup (`#0071`) fails test 21.

## Out of scope

- Testing every settings preference's effect (cursor style, font size).
- Testing theme application via UI (visual diffing is heavy).

## Notes

- Tests 19 and 20 (shell exit) depend on timing. Use the harness's `waitForCondition` with a 2-second timeout rather than a fixed sleep.
- Test 13 (drag-to-reorder) is the flakiest — XCUITest drag gestures need slow-paced events. If it's unreliable, accept that and document; SlidingTabs has its own model-level coverage.
- Related issues: `#0055`, `#0057`, `#0058`, `#0059`, `#0061`, `#0067`, `#0071`.
