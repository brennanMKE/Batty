## Description

Write the **Themes** section of Batty's user Help: `Batty/Help/07-themes.md`. Covers how to change the color scheme of every terminal in Batty.

Depends on `#0080` (Help window bootstrap).

## What `07-themes.md` covers

### Choosing a theme

- Menu bar → **Theme** → pick a name. A check mark next to the active theme.
- The choice applies to **all open terminals** immediately. Scrollback, running TUIs, the prompt — all re-render with the new colors. No restart needed.
- New tabs / sessions created afterward inherit the same theme.

### Where themes come from

Batty ships with a catalog of community-curated themes (the same set Ghostty uses). The list is built into the app; you don't need to install anything.

### Switching theme via Settings

Settings → Appearance shows the same theme picker as the menu, alongside font size and cursor style controls. The picker is a duplicate convenience — either path produces the same result.

### Persistence

Your theme choice is saved per-user. Quitting and relaunching Batty preserves it.

### What's *not* a theme

A theme controls the **terminal color palette** — foreground, background, and the sixteen ANSI colors plus the extended 256-color table. It does **not** control:

- The **font** (set in Settings → Appearance separately).
- The **cursor style** (block / bar / underline; Settings → Appearance).
- The **window chrome** (uses macOS system appearance).

### When a theme might not match what you expect

- Some TUIs (vim, neovim, htop) override colors via their own configuration. If those overrides reference ANSI palette slots (1–16), the theme is honored. If they hardcode hex colors, the theme is irrelevant for those parts.
- The shell's prompt is usually subject to your shell config, not Batty. A theme changes the palette your prompt's color codes resolve against, but if your prompt explicitly says "white background," that wins.

### Adding your own themes

v1: themes are baked into the app. Custom user themes (e.g. dropping a `.toml` into `~/Library/Application Support/Batty/themes/`) are a planned future feature, not available today.
