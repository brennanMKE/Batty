## Description

The UI test series [[0159]]–[[0169]] covers eleven major UI feature areas, but most of those features lack a dedicated reference doc in `docs/`. Engineers adding new tests or changing existing behavior have to reconstruct intended semantics from issue history and source code rather than a single authoritative doc. This issue creates `docs/ui-features.md` — a comprehensive reference covering each feature area: drag-and-drop, tab/session rename, theme application, layout picker, bell feed, tab chip rendering, workspace persistence, settings sheet, sidebar toggle, fuzzy finders, and modal confirmation flows.

## Expected behavior

`docs/ui-features.md` exists and covers:

- **Drag-and-drop** — file drop onto the terminal, pane swap within a session, cross-session drop, drop-zone mounting rules, AppKit z-order constraint summary.
- **Tab and session rename** — rename sheet flow, title-override precedence (manual name > resolver > shell title), Reset Title / Reset Name commands, per-cwd name persistence.
- **Theme application** — global theme, per-session override, fallback chain, where the resolved theme is surfaced for accessibility assertions.
- **Layout picker** — available presets, cwd inheritance from the focused pane, gating (disabled for multi-pane sessions), Session menu placement.
- **Bell feed** — BEL / OSC 9 capture, propagation chain (surface → pane → tab → session → window), click-to-jump navigation, per-session mute, focus/auto-clear, badge indicators.
- **Tab chip rendering** — chip width invariants (must not overflow pane edge), truncation rules, `+` button hit-testability, title resolution (override > resolver > shell > "~" for home dir).
- **Workspace persistence** — save triggers (structural change, 30s heartbeat), Codable round-trip, restore-on-launch semantics, corrupt-file recovery.
- **Settings sheet** — panes (General, Notifications, Shortcuts), preference persistence, multi-line paste default, hotkey rebind flow.
- **Sidebar toggle** — Cmd-B shortcut, Settings entry, animation expectations, button/chevron stability.
- **Fuzzy finders** — Command Palette (Cmd-Shift-P) and Open Quickly (Cmd-Shift-O): invocation, filtering, keyboard navigation, action dispatch, dismissal.
- **Modal confirmation flows** — multi-line paste sheet, close-with-process-running alert, quit confirmation; the `BATTY_UI_TEST_MODE` bypass and the second harness mode that auto-dismisses with a chosen outcome.

Each section should link back to the relevant issue series for historical context.
