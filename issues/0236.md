## Description

Phase 3 of the #0234 multi-window umbrella: make `TerminalHostStore` manage **one persistent `TerminalHostView` per content window** instead of a single `hostView`, per `docs/multi-window-design.md` §3. This is the highest-risk phase — it touches the terminal-lifetime architecture from #0072/#0074/#0075.

Scope:

- `TerminalHostStore.shared.hostView(forWindowID:)` lazily creates and permanently owns one host per `WindowID`; `TerminalHostInstaller` gains a `windowID` parameter and returns that window's host from `makeNSView` (still Pattern 3 from `docs/nsviewrepresentable-state-persistence.md`; `updateNSView`/`dismantleNSView` stay no-ops).
- `terminalViews` stays one tab-keyed map (sessions are partitioned, #0234 decision); the store records which window each tab's view lives in, and placement updates flow per window so one window's preference emissions cannot hide another's terminals.
- Host teardown only when its window closes and only after every tab in the window has gone through `releaseTerminalView(forTabID:)` — which remains the sole `removeFromSuperview` caller.
- Extend `docs/view-hierarchy.md` §§3–6 in the same change per the design doc's four amendments (never reparent across hosts; `attached host to window` fires once **per window**; window close routes through the per-tab close path; per-window placement maps guard cross-window churn).

With one window everything must behave byte-for-byte like today; multi-window behavior is only exercisable after #0237.

## Acceptance criteria

- `view.window` is the same `NSWindow` for the entire lifetime of every `AppTerminalView` (per-window invariant, `docs/view-hierarchy.md` §5).
- Log signals: `created`/`released terminal view` exactly once per tab; `attached host to window` exactly once per content window; no `io_exec: started subcommand` outside tab creation.
- `scripts/build.sh unit` passes; full UI suite passes; the manual `docs/terminal-pane-requirements.md` §6 checklist passes (pointer, keyboard, file/text drop, IME).
- `docs/view-hierarchy.md` updated for multi-host in the same commits.
