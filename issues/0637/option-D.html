Toolbar button states

Pending: alarm.fill, the normal toolbar tint. Tooltip: “Reminders (⌥⌘R) · 2 upcoming, next at 3:45 PM”.

Fired: alarm.waves.left.and.right.fill in the accent colour until dealt with. Tooltip: “Reminders (⌥⌘R) · 1 due, 2 upcoming”.

Every Session row is the same 28 pt height in every state. The title is untouched; the Reminder never adds a line. Same glyph rule as Option A.

Trade-offs

  • Clean split: the Bell Feed is terminal events the user missed; Reminders are things the user set. Neither list needs special cases for the other.
  • A visible, always-present entry point for New Reminder… and for reviewing what is pending.
  • Costs one more toolbar button and one more shortcut, and a missed Reminder is found under a different icon than a missed bell.
  • Bigger build than A: fired Reminders move out of the Bell Feed store into their own list, and the notification tap routing changes with them.
