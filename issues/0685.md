## Review notes

Round 1 (2026-11-19, reviewer): bounced for one blocking defect; everything else checks out.

**Blocking: `lastmod` mixes UTC "today" with git's committer-local date, so `--check` fails after a normal regenerate-then-commit.** `lastmod()` uses `datetime.now(timezone.utc)` for a dirty/untracked file but `git log -1 --format=%cs`, which prints the date in the committer's own UTC offset. In Pacific time from 16:00 to midnight (8 hours of every working day) these differ. Reproduced in a scratch clone at 18:49 PST: append to `website/privacy.html`, run the tool (sitemap gets `2026-11-20`), commit both, then `--check` exits 1 (git now says `2026-11-19`). Fix: make both sides use the same clock. Either take "today" as the local date, or read git's date in UTC (`git log -1 --format=%cd --date=format-local:%Y-%m-%d` with `TZ=UTC` in the subprocess env), and do the same in the self-test's `_today()`. Add a self-test that commits with a committer date whose local and UTC days differ (for example `GIT_COMMITTER_DATE="2026-01-01T20:00:00-0800"` and `TZ=America/Los_Angeles` in the env) and asserts the dirty-then-commit round trip passes `--check`.

**Also document (non-blocking, fold into the same round):** pages change on `issue/NNNN` branches and land by squash-merge, which creates a new commit with a new date. If the squash happens on a later day than the branch commit, `--check` on `main` goes stale. Say in `website/README.md` (and the Gotchas) that after squash-merging a branch that touched a `.html` page, run `python3 -I tools/build-site-index.py --check` on `main` and regenerate if needed, or have the tool's stale message say so.

Verified fine, no change needed: `llms.txt` follows llmstxt.org (H1, blockquote, paragraph, `## Docs`/`## Downloads`/`## Optional` link lists) and every site link exists except the DMG, whose exemption is documented; `llms-full.txt` drops generated markers, skips code fences, and rewrites relative links to absolute (only the documented release-day skill zip is not yet committed, and the file is held); `robots.txt` allows all and names the sitemap; `sitemap.xml` is valid XML (`xmllint`), lists five non-held pages, no `docs/`; `check-website-hold.py` passes; the #0688 rerun step is in `website/README.md` step 5. Self-test 13/13, `--check`, `check-website-hold(-selftest)`, `build-docs-page --check`, `build-cli-reference(-selftest) --check`, `build-backgrounds-page --check` all exit 0.
