# 0685 — The site serves no `llms.txt`, `llms-full.txt`, `robots.txt` or `sitemap.xml`

## Description

Child of #0680. Agents and crawlers look for a small set of well-known files. batty.sstools.co has none of them (`ls website/` shows no `llms.txt`, `llms-full.txt`, `robots.txt` or `sitemap.xml`). Add all four, generated where possible, using the defaults recorded on #0680: allow every crawler including AI crawlers, and publish `llms-full.txt`.

## Expected behavior

1. **`website/robots.txt`** (hand-written, tiny): `User-agent: *`, `Allow: /`, and `Sitemap: https://batty.sstools.co/sitemap.xml`. No per-bot blocks. It is not held: it can deploy with the next site deploy.
2. **`website/sitemap.xml`**, generated by `tools/build-site-index.py` (stdlib Python, `python3 -I`, `--check`, self-test) from the `.html` pages under `website/`, skipping any path listed in `website/.deploy-hold` (#0681). So it lists today's pages now, and the agent and CLI pages only after #0688 removes their hold entries and regenerates. `lastmod` comes from each file's last git commit date, so `--check` is stable.
3. **`website/llms.txt`** in llmstxt.org format, generated by the same tool: an H1 (`# Batty`), a one-line blockquote summary, a short paragraph, then `## Docs` linking `docs/index.md`, `docs/cli/index.md` and `docs/cli/capabilities.json`, `## Downloads` linking the skill zip (#0687) and the latest DMG, and `## Optional` linking `changelog.html` and GitHub. Links are absolute `https://batty.sstools.co/…` URLs. Held (listed in `.deploy-hold`), because every link in it points at held pages.
4. **`website/llms-full.txt`**, generated: `docs/index.md` and `docs/cli/index.md` concatenated under one heading each, with the source URL above each part. Held.
5. Markdown files are served as `text/markdown` or `text/plain` with UTF-8. The plan checks the photon server's MIME map read-only (`curl -sI` on an existing `.md`-like path, or ask the user) and records the result; any server config change is the user's to make.
6. `website/README.md` lists the new files under "Pages to spot-check" and adds `build-site-index.py --check` to the pre-deploy checks.

## Acceptance criteria

1. `python3 -I tools/build-site-index.py --check` and its self-test exit 0.
2. `llms.txt` has the llmstxt.org structure (H1, blockquote summary, link-list sections) and every link resolves to a committed file under `website/` (checked by the tool).
3. While `.deploy-hold` lists the agent paths, `sitemap.xml` contains none of them; the self-test proves removing a hold entry adds the page.
4. `robots.txt` allows all user agents and names the sitemap.
