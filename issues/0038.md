# 0038 — Sparkle auto-update integration

| | |
|---|---|
| **Status** | open |
| **Module** | Build |
| **Platform** | macOS |
| **First seen** | 2026-05-08 |

## Description

Wire Sparkle for auto-updates so users on direct downloads can stay current without manual reinstalls (PRD §11, Architecture dependencies).

**Acceptance criteria:**
- Sparkle SPM dependency added.
- `SUFeedURL` configured in Info.plist pointing at a `appcast.xml` we host.
- "Check for Updates…" menu item under the Batty menu.
- A signed appcast item served from our release flow can prompt users to update; the update applies on relaunch.
- EdDSA signing keys generated and the public key embedded in Info.plist; private key stored outside the repo.

## Notes

- Sparkle requires a hosted endpoint for the appcast. Decide on a hosting story (GitHub Pages? S3?) — note the chosen approach in the resolved Notes.
- Auto-update prompts should respect "Do not show again until next version" — Sparkle handles this by default.
