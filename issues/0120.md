## Description

Tier 3 localization target. Netherlands and Belgium (Flanders) — small but high-density developer market, strong English baseline, but Dutch UI is appreciated when it exists.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `nl` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Nederlands shows the full UI translated.
- Visual sweep for string-length expansion (~15–20% longer; Dutch compound nouns can run long).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- One `nl` covers both Netherlands Dutch and Flemish Dutch acceptably. Don't split into `nl-BE` unless a user reports a regional term that breaks.
- Terminology: "tabblad" (tab), "sessie" (session), "deelvenster" (pane). Confirm against Terminal.app's Dutch translations.
- Sparkle ships Dutch strings.

## Root cause

Foundation issue `#0107` shipped `Batty/Localizable.xcstrings` with English source plus a handful of reference locales, but Dutch (`nl`) had no `localizations` blocks. With Dutch absent from the catalog, macOS in Nederlands falls back to the English source for every Batty-owned string.

## Fix

Populate `nl` for every key in `Batty/Localizable.xcstrings`:

- Simple keys: `Batty` (brand kept Latin), `Quit Batty?` -> "Batty stoppen?", `Quit` -> "Stop", `Cancel` -> "Annuleer".
- Plural-aware keys carry both Dutch CLDR forms (`one`, `other`):
  - `Paste %lld lines?` -> "%lld regel plakken? / %lld regels plakken?"
  - `There %lld open terminal(s).` -> "Er is %lld terminal open. / Er zijn %lld terminals open."
  - `%lld unseen bell event(s)` -> "%lld ongelezen belmelding / %lld ongelezen belmeldingen"

Button verbs follow Apple's macOS Dutch conventions ("Stop" is what macOS uses on the Cmd-Q quit-confirmation button in nl; "Annuleer" is the standard imperative cancel). `%lld` specifiers preserved verbatim. Native review pending.

## Files changed

- `Batty/Localizable.xcstrings` — adds the `nl` localization block (with `one`/`other` plural variants where applicable) to all 7 catalog keys.

## Gotchas

- Translations are LLM-authored. A native-speaker pass is still owed before the Dutch UI is "final"; the per-language tier-3 acceptance criterion calls for that review.
- Apple's nl macOS uses "Stop" for the Cmd-Q quit confirmation button rather than alternatives like "Beëindig" or "Stoppen" — short and consistent with the system menu item. Don't change to a longer infinitive without checking Terminal.app / Finder against current macOS.
- Dutch UI conventions favor imperative singular for buttons ("Annuleer", "Stop", "Plak") in some places and infinitive in others ("Annuleren", "Stoppen", "Plakken"). Both forms appear across Apple's own apps; this catalog uses the imperative form Apple ships in macOS system alerts. If a future visual sweep shows inconsistency with Apple's current dialogs, switch to the infinitive form across the board.
- Dutch strings tend to expand 15-20% versus English and form long compound nouns ("belmelding", "deelvenster"). Watch fixed-width buttons and toolbar labels during a visual sweep.
- Sparkle's own UI ships its own Dutch strings — no work needed in this issue.
