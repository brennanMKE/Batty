## Description

The website has no demo page. `Demo.mp4` (streamable) and `Demo.jpg` (poster/screenshot) have been added to `website/` and should be presented on a dedicated `demo.html` page. The home page (`index.html`) should link to it.

## Steps to reproduce

1. Visit the Batty website home page.
2. Look for a way to preview the app in action.

## Expected behavior

A "Demo" or "Watch Demo" link on the home page leads to `demo.html`, which streams `Demo.mp4` using an HTML `<video>` element with `Demo.jpg` as the poster image.

## Actual behavior

No demo page exists. `Demo.mp4` and `Demo.jpg` sit in `website/` with no page referencing them.

## Notes

- `Demo.mp4` is set up for streaming — use `<video controls preload="none" poster="Demo.jpg"><source src="Demo.mp4" type="video/mp4"></video>`.
- Match the look-and-feel of the existing pages (`index.html`, `changelog.html`): shared CSS in `css/`, existing nav/footer patterns.
- The home-page link placement should be prominent — above the fold if possible, alongside or near the primary download CTA.
- Deploy is manual (user pushes `website/` via their own SSH config).

## Root cause

No `demo.html` page existed, and the home page had no link to a demo. The media assets (`Demo.mp4`, `Demo.jpg`) were present in `website/` but unreferenced and not gitignored, so they would have been accidentally committed.

## Fix

Created `website/demo.html` as a subpage matching the existing `changelog.html` structure: `page` body class, `page-header` with a back link, `prose` main content area, shared footer. The video element uses `preload="none"` and `Demo.jpg` as the poster per the issue spec.

Added a `cta-secondary` CSS class (outlined accent button) so the "Watch Demo" button can sit beside the existing "Download for macOS" CTA in the hero without competing visually. Both CTAs are above the fold. The footer nav also gains a Demo link alongside Changelog and Privacy. Added a responsive stacking rule so the secondary CTA drops below the primary on small screens. Also added `Demo.jpg` and `Demo.mp4` to `.gitignore` to prevent the large binaries from entering the index.

## Verification

HTML is well-formed. Page structure follows the established subpage pattern from `changelog.html`. No Xcode build involved — this is a pure website change. Visual sign-off is pending user review after deploy.

## Files changed

- `website/demo.html` — new demo page with `<video>` element, poster, back link, footer, and download CTA
- `website/index.html` — added "Watch Demo" CTA button in the hero and "Demo" link in the footer nav
- `website/css/style.css` — added `.cta-secondary` outlined button style and responsive stacking rule
- `.gitignore` — added `Demo.jpg` and `Demo.mp4` exclusions
