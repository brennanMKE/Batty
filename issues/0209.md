# 0209 — Website needs a demo page linked from the home page

| | |
|---|---|
| **Status** | open |

| **Platform** | macOS |
| **First seen** | 2026-05-21 |

## Description

The website has no demo page. `Demo.mp4` (streamable) and `Demo.jpg` (poster/screenshot) have been added to `website/` and should be presented on a dedicated `demo.html` page. The home page (`index.html`) should link to it.

## Steps to reproduce

1. Visit the Batty website home page.
2. Look for a way to preview the app in action.

## Expected behavior

A "Demo" or "Watch Demo" link on the home page leads to `demo.html`, which streams `Demo.mp4` using an HTML `<video>` element with `Demo.jpg` as the poster image.

## Actual behavior

No demo page exists. `Demo.mp4` and `Demo.jpg` sit in `website/` with no page referencing them.

## Notes

- `Demo.mp4` is set up for streaming — use `<video controls preload="none" poster="Demo.jpg"><source src="Demo.mp4" type="video/mp4"></video>`.
- Match the look-and-feel of the existing pages (`index.html`, `changelog.html`): shared CSS in `css/`, existing nav/footer patterns.
- The home-page link placement should be prominent — above the fold if possible, alongside or near the primary download CTA.
- Deploy is manual (user pushes `website/` via their own SSH config).
