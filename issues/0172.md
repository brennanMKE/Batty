# 0172 — Remove workspace persistence: source, docs, and spec

| | |
|---|---|
| **Status** | open |
| **Module** | App / Persistence / Docs |
| **Platform** | macOS |
| **First seen** | 2026-05-20 |

## Description

Workspace persistence was never a planned feature and will never be one. The four workspace source files (`Workspace.swift`, `WorkspaceConversion.swift`, `WorkspaceManager.swift`, `WorkspaceStore.swift`) and all call sites that write or reference them must be deleted. Every mention in `PRD.md`, `Concepts.md`, and `docs/` must also be removed or corrected.

`BattyApp.swift` currently routes the app's live `AppStateStore` through `WorkspaceManager.shared.store` — that wiring must be replaced so `AppStateStore` is owned and provided directly without the persistence layer in the middle.

## Source changes

### Delete entirely
- `BattyKit/Sources/BattyKit/Model/Workspace.swift` (117 lines — Codable snapshot structs)
- `BattyKit/Sources/BattyKit/Model/WorkspaceConversion.swift` (143 lines — live model → snapshot converters)
- `BattyKit/Sources/BattyKit/Runtime/WorkspaceManager.swift` (82 lines — save/load orchestrator, `WorkspaceManager.shared`)
- `BattyKit/Sources/BattyKit/Runtime/WorkspaceStore.swift` (109 lines — Codable file I/O)

### Update
- `Batty/BattyApp.swift` — replace `WorkspaceManager.shared.store` with direct `AppStateStore` construction/ownership at the app level (line 28: `.environment(\.appStateStore, ...)`, line 52: `QuitConfirmation.shouldQuitOrPrompt(store:)` call).
- Any other call sites that reference `WorkspaceManager`, `WorkspaceStore`, `WorkspaceConversion`, or the `Workspace` snapshot structs — grep for these and remove.
- `docs/notifications.md` — remove the `LayoutModel.Session.notificationsMuted` Codable field note (line ~259) and any other references to `workspace.json` round-tripping muted state.

## Doc and spec changes

### `Concepts.md`
- Remove the entire `## Workspace` section (currently ~lines 243–257) — the `workspace.json` file, write cadence, read cadence, and failure mode.
- Remove `**Workspace**` from the cross-cutting state list (line 23).
- Line 224: remove "Lifetime: persisted in the Workspace file; survives quit/relaunch" from the Bell Feed entry — bell feed history does not persist.
- Line 286: remove the Settings/Workspace distinction sentence.

### `PRD.md`
- Remove milestone M7 "Persistence" and its acceptance criteria.
- Remove the feature bullet "Persistence. Quit and relaunch — same sessions, panes, tabs, splits, and working directories." (line ~47).
- Remove the persistence section under section 6.7 (if present) and the `workspace.json` storage location entry.

### `docs/ui-features.md`
- Remove the `## Workspace persistence` section entirely (lines 381–433).
- Remove "workspace persistence" from the intro paragraph (line ~6).

### `docs/source-layout.md`
- Remove `WorkspaceStore` from the Runtime row and `Workspace`, `WorkspaceConversion` from the Model row.

## Acceptance criteria

- `xcodebuild -scheme 'Batty (Beta)' -destination 'platform=macOS' build` passes with zero errors.
- `grep -r "WorkspaceManager\|WorkspaceStore\|WorkspaceConversion\|workspace\.json" Batty/ BattyKit/Sources/` returns no results.
- No mention of `workspace.json` or layout persistence across launches remains in `PRD.md`, `Concepts.md`, or `docs/`.

## Notes

- `SessionNameCache` (the per-cwd name memory) is **not** part of this removal — it is a separate file, a separate concept, and a real planned feature.
- The Bell Feed history cap (200 entries) currently says "persisted across launches" in `Concepts.md` — that claim must be removed here too, since the persistence layer writing it is gone.
- Issue [[0165]] (UI test suite: workspace persistence) becomes moot; note this when closing that issue.
