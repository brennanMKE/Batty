## Description

Tier 3 localization target. Large developer community across Russia and CIS countries; many work cross-border and ship to global users. Common entry in Apple's localized-app set.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `ru` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Русский shows the full UI translated.
- Visual sweep for Russian string-length expansion (typically 20–30% longer than English; some compound nouns longer still).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Cyrillic renders cleanly in the default system font (SF Pro). No glyph-availability concerns expected.
- Watch for clipping in Settings labels — Russian is one of the longer Tier 3 locales.
- Sparkle ships Russian strings.

## Root cause

After `#0107` (catalog foundation) and the prior locale passes (`#0108`–`#0116`) landed, the `ru` column in `Batty/Localizable.xcstrings` was still empty for every key. Russian-speaking users on macOS — the large dev community across Russia and CIS countries — would fall back to the English source rather than seeing Apple-house-style Russian terminology with the correct three-form plural agreement that Russian grammar requires.

## Fix

Populated `ru` for every key in the catalog using Apple's macOS Russian house style (Apple Style Guide for Russian, Terminal.app and System Settings strings):

- `Batty` — passes through as the Latin-script brand name; no Бэтти transliteration, matching the catalog's never-translate-the-brand convention.
- `Quit Batty?` → `Завершить Batty?`. Apple's macOS Russian renders Cmd-Q's verb as Завершить (infinitive button label form), not Выйти.
- `Quit` → `Завершить`. Matches the alert title; Apple's File menu Quit entry on Russian macOS reads Завершить <App>.
- `Cancel` → `Отменить`. Apple's standard infinitive button label across alerts and sheets.
- `Paste %lld lines?` (plural) — three CLDR categories:
  - `one` → `Вставить %lld строку?` (counts ending in 1 but not 11: 1, 21, 31, …; noun in accusative singular)
  - `few` → `Вставить %lld строки?` (counts ending in 2–4 but not 12–14: 2, 3, 4, 22–24, …; noun in genitive singular)
  - `other` → `Вставить %lld строк?` (counts 0, 5–20, 25–30, etc.; noun in genitive plural)
- `There %lld open terminal(s).` (plural) — predicate gender/number also shifts:
  - `one` → `Открыт %lld терминал.` (masc. sg. short-form participle agreeing with sg. noun)
  - `few` → `Открыто %lld терминала.` (neuter sg. form used with the paucal "2–4" group)
  - `other` → `Открыто %lld терминалов.` (same neuter sg. with gen. pl. noun)
- `%lld unseen bell event(s)` (plural) — adjective + noun case shifts across all three forms:
  - `one` → `%lld непросмотренное событие звонка` (nom. sg. neuter)
  - `few` → `%lld непросмотренных события звонка` (gen. sg.; adjective takes the long-form gen. pl. ending used in the paucal group)
  - `other` → `%lld непросмотренных событий звонка` (gen. pl. throughout)

Format specifiers (`%lld`) preserved verbatim. `knownRegions` in `Batty.xcodeproj/project.pbxproj` left unchanged, matching the precedent set by every prior locale subagent (`#0108`–`#0116`).

## Files changed

- `Batty/Localizable.xcstrings` — added `ru` localizations for the 4 simple keys (`Batty`, `Quit Batty?`, `Quit`, `Cancel`) and the 3 plural-aware keys (`Paste %lld lines?`, `There %lld open terminal(s).`, `%lld unseen bell event(s)`), each with `one` / `few` / `other` plural variants per Russian CLDR rules.

## Gotchas

- **LLM-authored, not native-speaker reviewed.** Per the acceptance criteria, a native Russian speaker should still vet these. Word choices (Завершить vs Выйти for Quit, Отменить vs Отмена for Cancel, событие звонка vs событие колокольчика for "bell event") are judgment calls aligned with Apple's published macOS Russian terminology and the Apple Style Guide, but a native reviewer may want to revisit specific phrasings.
- **Russian has three CLDR plural categories — `one`, `few`, `other`.** Unlike English (one/other), zh-Hans/zh-Hant/ja/ko (other only, but the catalog still requires `one` to be present), or the Romance languages already in the catalog (one/other). All three plural-aware keys populate all three forms; the rendered noun form changes per count category (e.g. строку / строки / строк, терминал / терминала / терминалов, событие / события / событий). Omitting `few` would have caused the count 2, 3, 4, 22, … to fall through to the `other` form and produce grammatically wrong output like "Вставить 2 строк?".
- **Завершить vs Выйти for Quit.** Both are common in the wild; Apple's macOS specifically uses Завершить for the Cmd-Q verb (the literal `Quit %App%` menu item in Russian macOS reads `Завершить %App%`). Выйти reads more like "log out" or "exit" in Apple's house-style register and is what System Settings → Users uses for sign-out. Picked Завершить deliberately to match Apple convention; flag for native review if it reads unnaturally.
- **Predicate also inflects, not just the count noun.** For `There %lld open terminal(s).` the short-form participle Открыт/Открыто shifts between `one` (masc. sg. agreeing with терминал) and `few`/`other` (neuter sg., the impersonal form Russian uses with the genitive-noun paucal/plural construction). This is the right idiom — using one form across all three categories would be grammatically valid but read as unnatural Russian.
- **`knownRegions` in `Batty.xcodeproj/project.pbxproj` still does not list `ru`.** Following the precedent set by every prior locale subagent (`#0108`–`#0116`): registration in the Xcode Localization UI is only needed to make the catalog editor render the column; xcstringstool emits `ru.lproj/Localizable.strings` and `Localizable.stringsdict` correctly without it. Confirmed by inspecting the build product (`plutil -p .../ru.lproj/Localizable.strings` shows the four simple translations and `.stringsdict` shows the three plural keys with one/few/other variants).
- **Verified by build, not runtime.** `xcodebuild -scheme Batty -destination 'platform=macOS' build` passed (with `CODE_SIGN_IDENTITY=-` / `CODE_SIGNING_REQUIRED=NO` / `CODE_SIGNING_ALLOWED=NO`, mirroring the prior locale subagents). A full runtime visual sweep under `-AppleLanguages '(ru)'` — the acceptance criterion for clipping under Russian's ~20–30% string-length expansion in Settings, the bell feed popover, and alerts — has not been done and is part of what the user needs to confirm before this moves from `resolved` to `closed`.
