UI test `BattyUITests.SidebarTests.testCmdBCollapsesAndExpandsSidebar` (`BattyUITests/SidebarTests.swift:43`) fails with:

XCTAssertTrue failed

This test was created by [[0167]] as part of the UI test automation suite. The test was previously masked by the `Thread.sleep` runloop-blocking bug fixed in [[0170]] — the failure is now visible on every test run.

## Root cause

Same as [[0199]]: `BattyUITestHarness.sidebar(in:)` hard-coded
`app.collectionViews["session-sidebar"]`, but the SwiftUI
`List.listStyle(.sidebar)` renders as `NSOutlineView` on macOS. The
helper returned a non-existent element, so `waitForExistence` timed
out before the Cmd-B keypress was even sent.

## Fix

Resolved by code commit `01bb4b1` (see [[0199]]). Helper now tries
`collectionViews` → `outlines` → generic descendant query. Verified
locally with `scripts/run-ui-tests.sh
BattyUITests/SidebarTests/testCmdBCollapsesAndExpandsSidebar` — passes.
