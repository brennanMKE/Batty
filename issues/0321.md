## Description

Binding project docs assert things the source contradicts. Nothing user-facing is broken — this is documentation accuracy, not behavior — but #0302's whole premise was that this class of drift is expensive: these are the documents sessions and subagents are told to trust before touching code. Three specific line-level corrections, surfaced during #0302's review round 2 and explicitly deferred out of that issue's scope. All three claims were re-verified against the tree at filing time.

1. **`CLAUDE.md:12` lists "Workspace" among the canonical `Concepts.md` vocabulary terms, but `Concepts.md` has no `## Workspace` section.** The section was removed when #0172 deleted workspace persistence entirely (commit `5628db1`, "Remove workspace persistence: source files and call sites", 2026-05-20). The only remaining mention is the version footer at `Concepts.md:270`, a historical note recording the removal. Verified: `grep -n "^## " Concepts.md` lists Window, Session, Pane, Tab, Terminal Session, Split, Sidebar, Theme, Focus, Bell event, Bell Feed, System notification, Surface registry, Settings — no Workspace. This is the same staleness class #0302 fixed one line below it in the same file. (Note `CLAUDE.md:152` also mentions "Workspace persistence" under Architectural rules; #0302's diff addresses the persistence claim — check its final state before assuming it needs a second pass, and fix it here only if it survives the merge stale.)

2. **`docs/pane-kinds.md` §4 quotes #0172's "trimmed... to `SplitDirection` only" and then states that `LayoutModel.swift` today contains `SplitDirection` *and* `Pane { id, isHidden }`, without noting that `Pane` was re-added later by #0256** (commit `9cd5adc`, "Hide/show panes with sidebar pane tree and eye toggle", 2026-07-03 — the diff adds `public struct Pane` to `BattyKit/Sources/BattyKit/Model/LayoutModel.swift`). A reader hits what looks like a contradiction between the quoted issue and the described present state. One clause naming #0256 as the re-adder resolves it. Verified: `git show 9cd5adc -- BattyKit/Sources/BattyKit/Model/LayoutModel.swift` shows the `Pane` addition, and `grep -E "0256" docs/pane-kinds.md` (on `issue/0302`) returns nothing.

3. **Path citations in `docs/pane-kinds.md` are inconsistently abbreviated.** The document mostly cites full repo-relative paths (`BattyKit/Sources/BattyKit/Views/PaneView.swift:78-207`), but some citations are bare or wrongly prefixed: `TopologyPayload.swift:71` and `TopologyPayload.swift:66-81` are cited bare — the file lives in `BattyKit/Sources/BattyXPCCore/`, not under `BattyKit/Sources/BattyKit/` where the document's other citations point; and `BattyKitTests/TopologyPayloadTests.swift:183` actually lives at `BattyKit/Tests/BattyKitTests/TopologyPayloadTests.swift`. Harmless individually, but the document's stated purpose is that later children (#0303, #0304) can follow its citations without re-deriving them, so imprecise paths cost more there than elsewhere. Verified with `find`: both actual locations confirmed.

## Resolution notes

> 🟢 Resolved 2026-08-08 — all three statements corrected: "Workspace" is out of `CLAUDE.md`'s canonical-term list, `docs/pane-kinds.md` §4 now names #0256 as the commit that re-added `Pane`, and the four mis-prefixed path citations point at their real locations.

The citation item was swept rather than spot-fixed: every `file:line` citation in `docs/pane-kinds.md` was checked, and only the two the issue named were wrong.

## Root cause

Ordinary documentation drift, in three flavours. `CLAUDE.md:12` kept a vocabulary term whose `Concepts.md` section #0172 deleted. `docs/pane-kinds.md` §4 quoted #0172's "trimmed… to `SplitDirection` only" and then described a `LayoutModel.swift` containing `Pane`, without saying that #0256 put `Pane` back in between — so the two statements read as a contradiction. And the same document abbreviated two citation paths as though the files sat under `BattyKit/Sources/BattyKit/` when they don't.

## Fix

- `CLAUDE.md:12` — "Workspace" removed from the canonical-term list. `CLAUDE.md:152`, which the issue flagged as possibly also stale, turned out to have been corrected already by #0302's merge and needed no second pass.
- `docs/pane-kinds.md` §4 — a clause naming #0256 (commit `9cd5adc`, 2026-07-03) as re-adding `Pane` alongside the `isHidden` leaf property, placed at the point of apparent contradiction so the quoted #0172 line reads as history rather than as a present-tense claim.
- `docs/pane-kinds.md` — the four mis-prefixed citations corrected: three occurrences of `TopologyPayload.swift` (`BattyKit/Sources/BattyXPCCore/`) and one of `TopologyPayloadTests.swift` (`BattyKit/Tests/BattyKitTests/`).

`Concepts.md`'s version-footer note about workspace persistence was deliberately left alone — a version history recording that a feature was removed is correct, not stale.

## Review

Reviewer: `claude-opus-5`, two rounds.

Round 1 verified the citation sweep the hard way — all 28 `file:line` citations checked individually rather than sampled, printing each cited source line, including the content-sensitive ones where the document quotes what the line says. Every line number and range was accurate. It confirmed the path fix was complete rather than limited to the two named instances, and confirmed the `CLAUDE.md:152` reading via `git log -S`.

Then it found the one thing wrong with the diff, in the one sentence the diff added. The new clause said #0256 re-added `Pane` "for the sidebar pane-tree/eye-toggle feature, not for persistence." Both halves were false: #0256's own docstrings say `Pane` exists to *survive workspace persistence* (`LayoutModel.swift:10-14`, `PaneRuntime.swift:38`), and the eye-toggle feature reads `PaneRuntime.isHidden`, never the `Pane` type — whose only consumers are `snapshot()` and a Codable round-trip test. It also contradicted the next sentence in the same bullet, which calls `Pane` a dead type with no production caller.

Round 2 verified the correction against `git show 9cd5adc` and confirmed by word-level diff that the accompanying reflow changed exactly four words, all inside the sentence under repair.

## Gotchas

- **An accuracy sweep can introduce its own inaccuracy.** The only defect in this diff was in the only sentence it wrote from scratch; the mechanical corrections were all fine. Worth remembering the next time a documentation fix looks too small to review.
- **`Pane` is a live Codable type with no production caller.** `PaneRuntime.snapshot()` and one test are its only consumers. It exists because #0256 built it persistence-ready; #0172 had already removed the persistence that would have used it. Do not infer from its existence that anything serializes layout today.
