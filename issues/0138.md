# 0138 — Pin themes to the top of the theme selector

| | |
|---|---|
| **Status** | open |
| **Module** | Theme |
| **Platform** | macOS |
| **First seen** | 2026-05-19 |

## Description

Users should be able to pin themes so they appear in a dedicated "Pinned" section at the top of the theme selector (#0137). Pinning and unpinning is done from the Themes submenu in the file menu. The pinned set persists across launches.

## Expected behavior

- The View → Themes submenu (or wherever the theme list is surfaced in menus) shows a "Pin Theme" / "Unpin Theme" toggle for the currently active theme.
- Pinned themes appear in a visually separated "Pinned" section at the top of the theme selector grid, above all other themes.
- The rest of the grid continues in alphabetical order below the pinned section.
- Pinned state persists in `UserDefaults`.
- Pinning and unpinning from the menu is reflected in the selector immediately (no relaunch needed).

## Actual behavior

No pinning concept exists. All themes appear in a flat alphabetical list with no way to surface favorites.

## Notes

- Persist pinned theme IDs as `[String]` in `UserDefaults` (key e.g. `co.sstools.Batty.pinnedThemeIDs`). Order within the pinned section should match the order themes were pinned (first pinned = first shown), not alphabetical.
- The "Pin / Unpin" menu item should be context-sensitive: show "Pin Theme" when the active theme is not pinned, "Unpin Theme" when it is. Disable the item when no theme is active (system default).
- In the theme selector grid (#0137), the pinned section only appears when at least one theme is pinned. When the filter text field is non-empty, pinned themes that match the query should still float above non-pinned matches (or optionally collapse the section header and intermix — decide during implementation).
- A pin indicator on the card (small pin icon or a subtle highlight) makes it easy to see which themes are pinned without opening the menu.
- Prototype the pinned-section layout in the Themes sandbox app before wiring into Batty.
