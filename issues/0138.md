# 0138 — Pin themes to the top of the theme selector

## Description

Users should be able to pin themes so they appear in a dedicated "Pinned" section at the top of the theme selector (#0137). Pinning and unpinning is done from the Theme menu. The pinned set persists across launches.

## Expected behavior

- The Theme menu shows a "Pin Theme" / "Unpin Theme" toggle for the currently active theme.
- Pinned themes appear in a visually separated "Pinned" section at the top of the theme selector grid.
- The rest of the grid continues in alphabetical order below the pinned section.
- Pinned state persists in `UserDefaults`.
- Pinning and unpinning from the menu is reflected in the selector immediately.

## Actual behavior

No pinning concept exists. All themes appear in a flat alphabetical list.

## Notes

- Persist pinned theme names as `[String]` in `UserDefaults` (key `co.sstools.Batty.pinnedThemeIDs`).
- The "Pin / Unpin" menu item should be context-sensitive: show "Pin Theme" when the active theme is not pinned, "Unpin Theme" when it is. Disable when no theme is active.
- In the theme selector grid, pinned themes that match the filter query float above non-pinned matches.
- A pin indicator on the card makes it easy to see which themes are pinned.

## Root cause

No pinning concept existed. All themes appeared in a flat alphabetical list with no way to surface favorites.

## Fix

Implemented as part of #0137 (same code commit 3788252):

- `PinnedThemes` struct provides `load()`, `save()`, `toggle()`, and `contains()` against `UserDefaults` key `co.sstools.Batty.pinnedThemeIDs`.
- `ThemeSelectorView` splits `GhosttyThemeCatalog.allThemes` into `filteredPinned` and `filteredOthers`, renders them in two labeled grid sections. When the search field is non-empty, pinned matches still float above unpinned matches.
- `ThemeCard` shows a `pin.fill` / `pin` SF Symbol button in the card's name row; tapping calls `togglePin()` without selecting the theme.
- `BattyCommands` Theme menu has a context-sensitive "Pin Theme" / "Unpin Theme" item that is disabled when no theme is active.

## Files changed

All changes landed in the #0137 code commit. Same files as listed in 0137.md; no additional files were needed for pinning beyond what was implemented there.

## Gotchas

The "Pin Theme" / "Unpin Theme" state in the menu reads `PinnedThemes.load()` synchronously on each menu evaluation — appropriate for a small array but worth noting for large sets. Pinned order in the selector reflects insertion order (first pinned = first shown), not alphabetical.
