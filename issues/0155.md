# 0155 — Replace pane drag handle icon with squareshape.split.2x2.dotted.inside

| | |
|---|---|
| **Status** | open |
| **Module** | Pane |
| **Platform** | macOS |
| **First seen** | 2026-05-20 |

## Description

The pane drag handle currently uses the `rectangle.grid.1x2` SF Symbol. Swap it for `squareshape.split.2x2.dotted.inside`, which reads more clearly as a grippy/draggable affordance.

## Steps to reproduce

1. Open a session with at least one pane.
2. Look at the far-right of the pane tab bar.

## Expected behavior

Drag handle renders as `squareshape.split.2x2.dotted.inside`.

## Actual behavior

Drag handle renders as `rectangle.grid.1x2`.

## Notes

The icon is set in `BattyKit/Sources/BattyKit/Views/PaneView.swift` in the `paneDragHandle` view (around line 259). Only the `systemName` string needs to change; surrounding modifiers, hover cursor, and `.onDrag` behavior stay as-is.
