## Description

Tier 2 localization target. Solid macOS install base across France, Belgium, Switzerland, Canada, and Francophone Africa. Apple ships nearly every system app in French; missing French is a noticeable gap for non-trivial macOS apps.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `fr` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Français shows the full UI translated.
- Visual sweep for French string-length expansion (typically 15–25% longer than English) — Settings panes and alert buttons most at risk.
- `## Files changed` in the resolution should list the `.xcstrings` diff.

## Notes

- One `fr` covers both France French and Canadian French acceptably for software UI. Split into `fr-CA` only if a user reports a Quebec-specific term that breaks comprehension — rare for terminal-app UI.
- Use the **infinitive form** for menu items and buttons ("Quitter", "Coller") — standard macOS French convention. Apple's translator style guide is the canonical reference.
- Sparkle ships French strings.

## Root cause

`Localizable.xcstrings` had no `fr` translations after the localization foundation (`#0107`) landed. French-locale users saw English fallbacks throughout the UI.

## Fix

Populated every key in `Batty/Localizable.xcstrings` with French translations, using Apple's macOS French conventions (infinitive form for actions, *vous* form, standard terminology such as Quitter, Annuler, Coller). The brand fragment `Batty` stays Latin. Plural variations cover `one` (0, 1) and `other` (2+) per French CLDR rules. A non-breaking space (U+00A0) precedes `?` per French typography, matching Apple's own French UI strings.

## Files changed

- `Batty/Localizable.xcstrings` — added `fr` entries for all 7 keys (Batty, Paste %lld lines?, There %lld open terminal(s)., %lld unseen bell event(s), Quit Batty?, Quit, Cancel).

## Gotchas

- Translations are LLM-authored, not native-speaker reviewed; a francophone pass before release is still advisable (per the issue's acceptance criteria).
- Used U+00A0 (NBSP) — not U+202F (narrow NBSP) — before `?` to match Apple's existing French system strings. Confirm on visual review that the gap reads as expected; some apps prefer the narrower form.
- Adopted the *vous* register and Apple's "Quitter / Annuler / Coller" infinitives, consistent with Terminal.app and macOS Système.
- `Batty` kept as-is in "Quitter Batty ?" — the catalog's brand entry stays Latin per project convention.
- French is typically 15–25% longer than English; layout sweep for the Settings panes and alert buttons still needs to happen visually before closing.
- Catalog-only change; no Swift source touched. No un-localized literals encountered during this task.
