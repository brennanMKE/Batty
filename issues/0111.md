## Description

Tier 2 localization target. Solid macOS install base across France, Belgium, Switzerland, Canada, and Francophone Africa. Apple ships nearly every system app in French; missing French is a noticeable gap for non-trivial macOS apps.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `fr` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Français shows the full UI translated.
- Visual sweep for French string-length expansion (typically 15–25% longer than English) — Settings panes and alert buttons most at risk.
- `## Files changed` in the resolution should list the `.xcstrings` diff.

## Notes

- One `fr` covers both France French and Canadian French acceptably for software UI. Split into `fr-CA` only if a user reports a Quebec-specific term that breaks comprehension — rare for terminal-app UI.
- Use the **infinitive form** for menu items and buttons ("Quitter", "Coller") — standard macOS French convention. Apple's translator style guide is the canonical reference.
- Sparkle ships French strings.
