## Description

Add the user-facing controls that split the focused Pane: SF Symbol toolbar buttons and keyboard shortcuts. Per `Concepts.md` → Split, `rectangle.split.2x1` splits horizontally (side-by-side) and `rectangle.split.1x2` splits vertically (stacked). New panes are born with one Tab containing one fresh Terminal Session in the parent's cwd.

**Acceptance criteria:**
- Two SF Symbol buttons appear in the session toolbar:
  - `rectangle.split.2x1` → split focused Pane horizontally; new Pane to the right.
  - `rectangle.split.1x2` → split focused Pane vertically; new Pane below.
- Keybindings:
  - **Cmd-D** — split horizontally (matches the toolbar button).
  - **Cmd-Shift-D** — split vertically.
- Both controls operate on the **focused Pane** in the active Session.
- The split inserts a new `.split(...)` node in place of the focused leaf, with the original leaf and a new leaf as children. Default ratio is 0.5.
- New leaf: one Pane, one Tab, one Terminal Session in the focused Pane's cwd.

## Notes

- Toolbar buttons may live in the window toolbar, the session toolbar, or a per-pane hover overlay (TBD per PRD §6.4 — decide during implementation).
- The new Pane should take focus immediately so the user can start typing.
- Does not include divider drag (#0019), focus movement (#0020), or last-tab collapse (#0021).
