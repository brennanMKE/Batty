## Description

**HIGH. Related to #0601.** Two status-Pane models re-render their whole view on a timer even when nothing visible changed, inside the detail column's `NSHostingView`:

1. `ProcessStatusPaneContent` rebuilds `snapshot` every 1 s tick with `capturedAt: Date()`. `Snapshot` is `Equatable`, but the fresh `Date` makes every write unequal, so `ProcessStatusPaneView` re-renders at 1 Hz for an idle process, and for a permission-denied target whose all-nil snapshot is rebuilt each tick. `capturedAt` is shown only in the exited and unavailable banners.
2. `LMStudioDashboardPaneContent.pollPsOnce` runs `inFlight.removeAll { … }` on every `lms ps` poll (3 s). An in-place `_modify` mutation always notifies, even when nothing is removed, so `LMStudioDashboardView` re-renders every 3 s while connected with nothing in flight. (`evictStaleInFlight` right above it is already guarded.)

Also, several `@Observable` types keep implementation details observed: tasks, timers, samplers, generations and provider closures. No view reads them today, so they cost only registrar traffic, but any future computed property a view reads would pick them up silently.

## Rule violated

- `docs/swiftui-observation-rules.md`, "Ownership and passing rules": caches, delegates, closures, pending `Task`s and timers inside an `@Observable` type are `@ObservationIgnored`; hot-path mutators are idempotent at the store.
- Same doc, "Observation semantics": in-place mutations and unequal values always notify.
- swift-guidance `swiftui-observation.md`: no per-tick timestamps in observed state a view doesn't show.

## Evidence

- **Proven:** all of the above by reading the code.
- **Inferred:** cost per tick; measurable with `StatusPaneLayoutConvergenceTests`' fixtures.

## Fix direction

- Process Status: move the timestamp out of the `Equatable` `Snapshot` (e.g. `@ObservationIgnored var lastSampleAt: Date?`, or an observed `lastSeenAt` written only on the transition into `.exited`/`.unavailable`, which is when the banners appear). In the permission-denied branch, keep the previous snapshot when pid and identity are unchanged.
- LM Studio: compute `let kept = inFlight.filter { … }` and assign only when `kept.count != inFlight.count`.
- Add `@ObservationIgnored` to the listed implementation details. Leave `GitStatusPaneContent.isRefreshing` observed (it drives a spinner).
