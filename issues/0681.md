2. **`tools/check-website-hold.py`** (new, stdlib only, `python3 -I`, shebang `#!/usr/bin/env python3`, module docstring with usage like `check-backgrounds.py`). Structure as importable functions so the self-test can load it with `importlib` (same pattern as `tools/check-backgrounds-selftest.py`):
   - `parse_hold(text) -> list[HoldEntry]`: skip blank and `#` lines; strip whitespace; each entry must start with `/`, contain no `*?[` and not start with `+ `/`- `; otherwise raise a `HoldFormatError` naming the line number. An entry ending in `/` is a directory prefix (`docs/`), otherwise an exact file (`llms.txt`).
   - `is_held(site_path, entries) -> bool`: `site_path` is a normalised path relative to the site root, no leading slash. Directory entry matches `docs` itself and anything starting `docs/`; file entry matches exactly.
   - `extract_refs(text, kind)`: for `html`, an `html.parser.HTMLParser` subclass collecting `href`, `src`, `srcset` (split on commas, first token of each), `poster`, `data`, `action` and `content` of `<meta http-equiv="refresh">` (the `url=` part). For `xml` (sitemap), every `<loc>` text and every `href=` attribute (regex is fine). For `robots`, the value of `Sitemap:`, `Allow:` and `Disallow:` lines. Return raw strings.
   - `resolve(ref, page_rel) -> str | None`: drop refs starting `#`, `mailto:`, `tel:`, `javascript:`, `data:`; strip `?query` and `#fragment`; an absolute URL counts only if its host is `batty.sstools.co` (http or https), then use its path; other hosts return `None`. A path starting `/` is site-root relative. Otherwise join with `posixpath` against the page's directory (`""` for top-level pages). Normalise with `posixpath.normpath`, strip the leading `/`; a path that escapes the root (`..`) returns `None`. A ref to a directory (`docs/`) normalises to `docs`, which `is_held` matches.
   - `main(argv)`: `--site DIR` (default `<repo>/website`, from `Path(__file__).resolve().parent.parent`), `--hold FILE` (default `<site>/.deploy-hold`). Pages scanned: `<site>/*.html` (top level only, sorted), plus `<site>/sitemap.xml` and `<site>/robots.txt` when they exist. For each held reference print `<page>:<line>: links held path <path> (held by <entry>)` to stderr. Exit codes: 0 clean, printing one line `OK: <pages> pages checked, <entries> held entries`; 1 when any page links a held path; 2 on a missing/unreadable hold file or a `HoldFormatError` (message to stderr). Line numbers: `HTMLParser.getpos()` for HTML, line index for the text formats.

Cases, each an `assert` with a message, printing `OK: <n> cases` at the end:
