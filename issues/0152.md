# 0152 — Layout picker should be disabled for multi-pane sessions and surfaced in the Session menu

| | |
|---|---|
| **Status** | open |
| **Module** | App / Session / Layout |
| **Platform** | macOS |
| **First seen** | 2026-05-20 |

## Description

The layout picker (Cmd-Shift-L, "Layouts…") is designed to quickly set up a fresh single-pane session into a multi-pane arrangement. Once a session already has more than one pane the picker silently does nothing (`PaneLayout.apply(to:)` guards on `tree.allPanes.count == 1`), but the menu item remains enabled, giving no feedback to the user about why nothing happened.

Two improvements are needed:

1. **Disable the menu item** when the selected session has more than one pane, so the enabled state accurately reflects whether the action can do anything.
2. **Add "Choose Layout…" to the Session menu** with an appropriate SF Symbol. The layout picker is a session-setup tool — it belongs conceptually in the Session menu, not only in the Pane menu. The Pane menu entry can remain as a secondary access point or be removed; the Session menu is the primary home.

## Expected behavior

- "Choose Layout…" (or "Layouts…") appears in the Session menu with the `rectangle.3.group` SF Symbol and the Cmd-Shift-L shortcut.
- The menu item is enabled only when the selected session has exactly one pane (`selectedSession?.tree.allPanes.count == 1`). It is disabled (greyed out) when there is no session or when the session already has multiple panes.
- The existing "Layouts…" item in the Pane menu should be updated with the same disable condition.

## Actual behavior

- "Layouts…" exists only in the Pane menu with no SF Symbol.
- It is disabled only when `selectedSession == nil`. A session with 2+ panes still shows the item as enabled, even though activating it does nothing.

## Notes

- The disable predicate in `BattyCommands.swift` (line 154) currently reads `.disabled(store.selectedSession == nil)`. It needs to change to `.disabled(store.selectedSession?.tree.allPanes.count != 1)` (which also covers the nil case since optional chaining returns nil, not 1).
- `rectangle.3.group` is the standard macOS symbol for multi-pane / layout concepts and is used by other apps for similar grid-arrangement features.
- Related to #0148 (CWD inheritance in layout picker), #0151 (SF Symbols across menus).
