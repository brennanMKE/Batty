# 0020 — Pane focus movement (Cmd-Option-arrows) and split resize (Cmd-Ctrl-arrows)

| | |
|---|---|
| **Status** | open |
| **Module** | Split / Pane |
| **Platform** | macOS |
| **First seen** | 2026-05-08 |

## Description

Keyboard-only navigation through panes. Two related sets of shortcuts:

- **Cmd-Option-arrows** move focus between Panes within the active Session (Concepts → Pane → "Focus movement").
- **Cmd-Ctrl-arrows** resize the Split containing focus by ±5% in the indicated direction.

**Acceptance criteria:**
- Cmd-Option-Left / Right / Up / Down move focus to the spatially-adjacent Pane in that direction.
- Movement is geometric, not tree-order: Cmd-Option-Right moves to the Pane immediately right of the focused one, regardless of how the split tree is shaped.
- If no Pane exists in that direction, the keypress is a no-op.
- Cmd-Ctrl-Left / Right / Up / Down resize the relevant split divider by ±5%.
- Cmd-Ctrl-Up shrinks a vertical split's top child; Cmd-Ctrl-Down expands it (analog for horizontal). Document the convention in code so it's consistent.
- Both sets of shortcuts appear in the menu bar.

## Notes

- The geometric algorithm for Cmd-Option-arrows: from the focused Pane's frame, find the candidate Pane whose frame is on the indicated side and whose center is closest to the source's center.
- Cmd-Ctrl-* may collide with macOS Mission Control / Spaces shortcuts on some user setups. Document the conflict if it arises; we don't change Apple's defaults.
