## Description

Phase 2 of the #0234 multi-window umbrella: introduce the `WindowRuntime` per-window state container around `AppStateStore` with **exactly one window and zero behavior change** — a pure refactor that creates the seam every later phase plugs into. Design source: `docs/multi-window-design.md` §5 (the per-window state model) and §1 (current state).

Scope:

- New `@Observable` `WindowRuntime` (`BattyKit/Sources/BattyKit/Runtime/WindowRuntime.swift`), named per the `SessionRuntime`/`PaneRuntime`/`TabRuntime` family, with a stable `id` (`WindowID` wrapping a `UUID`).
- Move per-window state and behavior out of `AppStateStore` into `WindowRuntime` per the design doc's table: `sessions`, `selectedSessionID`/`selectedSession`, session CRUD (`addSession`, `removeSession`, `renameSession`, `duplicateSession`, `moveSessions`, `selectSession(at:)`), the `closeTab(id:)` cascade, `pendingCloseRequest` + confirm/cancel, and `focusPane(id:)`/`focusPane(containingTabID:)`.
- `AppStateStore` keeps the global services (bell routing across windows, `bellFeed`, `nameCache`, `themeChrome`, AI naming, `notifier`) and gains `windows: [WindowRuntime]` + `windowRuntime(for:)`; with one window, every existing call site resolves to the single runtime.
- `BattyShortcuts`, `BattyCommands`, and the view layer re-target through the single `WindowRuntime`; sidebar visibility plumbing stays as-is in this phase (it moves per-scene in #0238).

This phase touches selection and focus flow, so `docs/swiftui-observation-rules.md` is binding and must be re-read before starting; equal-value `@Observable` writes re-invalidate (#0229 lineage) — preserve the existing idempotency guards (e.g. `focusPane(id:)`).

## Acceptance criteria

- Pure refactor: no user-visible behavior change of any kind.
- `scripts/build.sh unit` passes with **no test edits** beyond mechanical API renames, and the full UI suite (`scripts/run-ui-tests.sh`, Mac mini) passes unmodified.
- No new writes to observed state from view-update code; focus/selection writers unchanged in origin.
