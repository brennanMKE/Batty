# 0670 — Remove the `serverPane` feature flag so Server Panes, Web Preview Panes and `batty server` ship in Prod

|---|---|

## Description

Child of #0660. The Server Pane (#0648, #0658) and the static server and Web Preview Pane (#0649) ship in 1.5.0, so the `serverPane` flag goes in 1.5.0 (`AGENTS.md`, "Release branches"). After this, Prod has the `server` noun (`start`, `attach`, `serve`, `preview`, `stop`, `restart`), both Pane kinds and the Settings › General › Server Panes rows.

### Current state

`FeatureFlags.serverPane` and its UI-test force-off override `BATTY_UI_TEST_FORCE_SERVER_PANE_OFF` (`BattyKit/Sources/BattyXPCCore/FeatureFlags.swift:13, 25-27, 54-60`). Gate sites, as recorded in `docs/feature-flags.md`:

- `BattyCLI.subcommands(for:)` (`BattyKit/Sources/batty/BattyCLI.swift:29-31`): `ServerNounCommand` only with the flag; `CapabilitiesCommand.verbs(flags:)` / `buildPayload(flags:)` take the flags.
- `AppStateStore.startServerForXPC` / `attachServerForXPC` / `stopServerForXPC` / `restartServerForXPC` (`BattyKit/Sources/BattyKit/Runtime/AppStateStore+Server.swift:176, 226, 248`) and `serveStaticForXPC` / `openWebPreviewForXPC` (`AppStateStore+StaticServer.swift:53, 123`) fail with `.flagOff`.
- `GeneralSettingsView(showsServerPanes:)` (`BattyKit/Sources/BattyKit/Views/SettingsView.swift:17`).
- Not flag-dependent and staying: `PaneContentKind.paneSplitKinds` / `projectSlotKinds` exclude `.server` and `.webPreview`, and `AppXPCService.paneSplitRefusal` refuses them.
- Flag-off tests to delete: `AppStateStoreServerTests.everyVerbFailsWithFlagOff`, `ServerCapabilitiesTests.serverVerbsAppearOnlyWithTheFlagOn`, `CapabilitiesCommandTests.flagOffPayloadHasNoServerVerbs`, `AppStateStoreStaticServerTests.serveFailsWithFlagOff`, `AppStateStoreWebPreviewTests.previewFailsWithFlagOff`, `BattyUITests/CLIServerPaneTests/testServerVerbsAbsentWithFlagForcedOff`, `BattyUITests/CLIWebPreviewTests/testServeAndPreviewAbsentWithFlagForcedOff`.

## Expected behavior

- Delete `serverPane`, the `.flagOff` error case if nothing else uses it, `uiTestForceServerPaneOffVar` and `applyingUITestOverride` (if no other flag uses the override), and every gate, taking the flag-on branch.
- Delete the flag-off tests listed above; `./build.sh ui-typecheck` must pass after removing the two UI tests.
- Update `docs/feature-flags.md`: move `serverPane` to "Retired flags" ("added in #0648, removed in 1.5.0 by #0670").

## Acceptance criteria

1. `git grep -n "serverPane\b\|FORCE_SERVER_PANE_OFF"` finds no flag reference outside "Retired flags" and issue files (`serverPanePlacementKey` and other non-flag names stay).
2. `CapabilitiesCommandTests` asserts the `server` verbs are in the payload built with Prod's flags.
3. `./build.sh`, `./build.sh unit` and `./build.sh ui-typecheck` pass.

## Open questions

1. **The two design docs** (`docs/design/server-pane-view.md`, `docs/design/web-preview-pane.md`) were left awaiting the user's approval in #0646's Gotchas. Recommended: the user signs them off before this lands, since it puts both views in front of Prod users.
