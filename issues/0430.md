## Description

This is the Git Status / scanner child of umbrella [#0427](0427.md), and it is **blocked by [#0428](0428.md)** (the shared clock, readiness helper, completion-signal conventions and reap gate). It covers 29 sites. `GitStatusPaneContent` debounces through a real `Task.sleep(nanoseconds: debounceNanoseconds)` (`Runtime/GitStatusPaneContent.swift:761`). It exposes `handledScanResultCount` (`:669`) and `awaitPendingTeardownReapsForTesting()` (`:397`), but no scan-completion event. So the tests poll `waitUntil` to a 15s deadline, use a real scan delay to hide mid-scan, and rely on 20–30ms windows to show that nothing deferred or periodic happened.

Work: route the debounce and all deferred/periodic work through #0428's clock protocol, so the fake's pending-work count becomes the "nothing scheduled" proof. Add a scan-handled event in the shape #0428's conventions prescribe. Gate the fake scanner with a continuation. Then rewrite each row below.
