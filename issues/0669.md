## Description

Child of #0660. The agent integration ships in 1.5.0, so its flag goes in 1.5.0 (`AGENTS.md`, "Release branches": "Remove the flag in the release that ships the feature"). After this, Prod `batty` has `mcp`, `agent install` and `agent context`, and Prod Settings has the AI Agents section, exactly like Beta.

### Current state

`FeatureFlags.agentIntegration` (`BattyKit/Sources/BattyXPCCore/FeatureFlags.swift:12, 15-18, 36, 40, 51`). Gate sites, as recorded in `docs/feature-flags.md` ("Current flags"):

- `BattyCLI.subcommands(for:)` (`BattyKit/Sources/batty/BattyCLI.swift:33-35`): `MCPCommand` and `AgentNounCommand` only with the flag.
- `CapabilitiesCommand.skillInstallLines(cliVersion:flags:)` (`BattyKit/Sources/batty/CapabilitiesCommand.swift:301`): `agent install` line with the flag, the `git clone` recipe without.
- `AdvancedSettingsView` (`BattyKit/Sources/BattyKit/Views/SettingsView.swift:497`): AI Agents section only with the flag.
- Anything #0661–#0668 gated on it while this flag existed (`agent context`, `tab new`, `--wait`, the setup offer); each of those issues records its gate site.

## Expected behavior

- Delete `agentIntegration` from `FeatureFlags` (keep `sharedProjectImages`, and `serverPane` until #0670), fix every compile error by taking the flag-on branch.
- Plain-text `capabilities` always points at `agent install`; delete the `git clone` recipe if nothing else uses it.
- Delete the flag-off tests for it, and update `docs/feature-flags.md`: move `agentIntegration` to "Retired flags" ("added in #0647, removed in 1.5.0 by #0669").
- Grep `docs/`, `.claude/skills/batty-cli/SKILL.md`, `BattyKit/Sources/BattyKit/AgentGuidance/` (if present) and Help for "Beta only" wording about `mcp`/`agent`; leave the prose rewrite to #0671 but list what it must change.

## Acceptance criteria

1. `git grep -n agentIntegration` returns only `docs/feature-flags.md`'s "Retired flags" line and issue files.
2. `CapabilitiesCommandTests` asserts `mcp`, `agent install` and `agent context` are in the payload built with Prod's flags.
3. `./build.sh`, `./build.sh unit` pass; `./build.sh ui-typecheck` if UI tests changed.

## Open questions

None. Land after #0661–#0668 so nothing half-done reaches Prod; if 1.5.0 is cut before one of them, that one keeps its own gate or moves to the next release.
