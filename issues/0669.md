## Description

Child of #0660. The agent integration ships in 1.5.0, so its flag goes in 1.5.0 (`AGENTS.md`, "Release branches": "Remove the flag in the release that ships the feature"). After this, Prod `batty` has `mcp`, `agent install` and `agent context`, and Prod Settings has the AI Agents section, exactly like Beta.

### Current state

`FeatureFlags.agentIntegration` (`BattyKit/Sources/BattyXPCCore/FeatureFlags.swift:12, 15-18, 36, 40, 51`). Gate sites, as recorded in `docs/feature-flags.md` ("Current flags"):

- `BattyCLI.subcommands(for:)` (`BattyKit/Sources/batty/BattyCLI.swift:33-35`): `MCPCommand` and `AgentNounCommand` only with the flag.
- `CapabilitiesCommand.skillInstallLines(cliVersion:flags:)` (`BattyKit/Sources/batty/CapabilitiesCommand.swift:301`): `agent install` line with the flag, the `git clone` recipe without.
- `AdvancedSettingsView` (`BattyKit/Sources/BattyKit/Views/SettingsView.swift:497`): AI Agents section only with the flag.
- Anything #0661–#0668 gated on it while this flag existed (`agent context`, `tab new`, `--wait`, the setup offer); each of those issues records its gate site.

## Root cause

Feature work. `agentIntegration` (#0647) gated `batty mcp`, `batty agent install|context`, the plain-text `capabilities` install pointer, the Settings → Advanced "Command Line and AI Agents" sections and the launch refresh hook `AppStateStore.startAgentSetupCheck`, all off in Prod. With #0661–#0668 resolved, the flag ships on in 1.5.0.

## Fix

Followed the plan. Deleted the property and took the flag-on branch at every gate site; `skillInstallLines()` now always returns the `agent install` pointer, and the `git clone` recipe, `skillRepositoryURL` and `skillRepositoryRelativePath` are gone; `plainTextSummary` lost its `flags` parameter. Settings always shows the agent sections; `CLIInstallRow.showsAgentGuidance` removed. Launch refresh hook only skips UI-test launches; `AgentSetupCoordinator.runLaunchCheck` still does nothing without a record, so a fresh install writes and prompts nothing. `servers` untouched. One divergence: `CapabilitiesInputSchemaTests.leafArchetypeByVerbPathCoversExactlyTheShippedVerbPaths` compared the flag-off tree to keys minus `MCPToolCatalog.excludedVerbPaths`; the flag-off tree now contains `mcp`/`agent`, so it subtracts only the server paths.

Left for #0671: SKILL.md §9/§10, the "Beta only until 1.5.0" server wording in `docs/batty-cli-agent-workflows.md`, `docs/batty-cli-design.md` §1.1, `docs/batty-cli-install.md` server rows and `Concepts.md:98`, and a Help page for agents.
