## Description

Tier 2 localization target. European Spanish (Castellano) for users in Spain and the smaller European Spanish-speaking population.

Depends on `#0107`. Pairs with `#0113` (Latin American Spanish, `es-419`), which is filed separately because terminology differs enough — particularly for tech / computer vocabulary — that a single neutral `es` reads awkwardly on either side of the Atlantic.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `es` translation, reviewed by a native European Spanish speaker.
- Launching with macOS Language & Region set to Español (España) shows the full UI translated.
- Visual sweep for Spanish string-length expansion (~15–20% longer than English).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Use "vosotros" / "tú" conventions consistent with Apple's macOS Spanish localizations.
- Terminology hints: "pestaña" (tab), "panel" or "panel dividido" (split pane), "sesión" (session), "atajo" (shortcut). Confirm against Terminal.app's Spanish translations to keep parity with user expectations.
- Sparkle ships Spanish strings (one generic `es`, not regional).
