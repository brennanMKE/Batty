## Description

Tier 2 localization target. European Spanish (Castellano) for users in Spain and the smaller European Spanish-speaking population.

Depends on `#0107`. Pairs with `#0113` (Latin American Spanish, `es-419`), which is filed separately because terminology differs enough — particularly for tech / computer vocabulary — that a single neutral `es` reads awkwardly on either side of the Atlantic.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `es` translation, reviewed by a native European Spanish speaker.
- Launching with macOS Language & Region set to Español (España) shows the full UI translated.
- Visual sweep for Spanish string-length expansion (~15–20% longer than English).
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Use "vosotros" / "tú" conventions consistent with Apple's macOS Spanish localizations.
- Terminology hints: "pestaña" (tab), "panel" or "panel dividido" (split pane), "sesión" (session), "atajo" (shortcut). Confirm against Terminal.app's Spanish translations to keep parity with user expectations.
- Sparkle ships Spanish strings (one generic `es`, not regional).

## Root cause

`Localizable.xcstrings` had no `es` translations after the localization foundation (`#0107`) landed. Users running macOS with Language & Region set to Español (España) saw English fallbacks throughout the UI.

## Fix

Populated every key in `Batty/Localizable.xcstrings` with European Spanish translations using Apple's macOS Spanish (Spain) conventions: imperative/impersonal forms for buttons and menu items (Salir, Cancelar, Pegar), inverted opening punctuation `¿…?` for questions, and standard Castilian terminology. The brand fragment `Batty` stays Latin. Plural variations cover `one` (1) and `other` (0, 2+) per Spanish CLDR rules.

## Files changed

- `Batty/Localizable.xcstrings` — added `es` entries for all 7 keys (Batty, Paste %lld lines?, There %lld open terminal(s)., %lld unseen bell event(s), Quit Batty?, Quit, Cancel).

## Gotchas

- Translations are LLM-authored, not native-speaker reviewed; a Castilian-Spanish pass before release is still advisable per the issue's acceptance criteria.
- This locale is `es` (Spain). `#0113` covers Latin American Spanish (`es-419`) separately. Key Spain-vs-LatAm distinctions to watch: Spain prefers *ordenador* (LatAm: *computadora*), *móvil* (LatAm: *celular*), and the *vosotros* second-person plural — though most macOS UI uses impersonal/imperative forms and therefore reads the same across regions. The strings in this catalog skew impersonal, so divergence with `es-419` is minimal here; expect more separation as the catalog grows.
- Used inverted opening punctuation (`¿`, `¡`) per RAE / Apple Spanish style. Plain question/exclamation marks would read as Anglicized.
- Chose **Salir** for the Quit verb (Apple's macOS Spanish convention) rather than *Cerrar* or *Terminar*. Matches the standard "Salir de <app>" alert title pattern used by Apple system apps.
- "Tipo de letra" is Apple Spain's term for *Font* — kept in reserve for future Settings strings; the current catalog has no Font key yet, so no occurrence here. (LatAm tends to use *Fuente*; another point where `es` and `es-419` will diverge as the catalog grows.)
- Spanish runs roughly 15–20% longer than English; layout sweep for Settings panes and alert buttons still needs visual confirmation before closing.
- Catalog-only change; no Swift source touched. No un-localized literals encountered during this task.
