## Description

Surface bell events outside the Bell Feed popover — both via macOS Notification Center and via inline visual indicators. Concepts → Bell event ("Visual feedback") and → System notification.

**Acceptance criteria:**
- **System notifications:** when the app is not frontmost OR when the source is in a non-active Session/Pane/Tab, post a `UNNotificationRequest`:
  - Title: `Batty — <Session> › <Pane› › <Tab>`.
  - Body: OSC 9 message if present, else `"Bell"`.
  - Tapping invokes #0027's click-to-jump flow.
- **Per-Tab dot:** SlidingTabs' `hasUnseen` is bound to `tab.unseenBellCount > 0`.
- **Per-Pane border:** subtle accent flash on bell, fading over ~1s; sustained dot/border tint when an inactive Tab in the Pane has unseen bells.
- **Per-Session sidebar badge:** small dot or count badge on the Session row when any descendant has unseen bells.
- Settings expose: notification sound on/off, system notifications on/off, per-Session mute toggle (lives in the Session context menu — see follow-up if needed).

## Notes

- `UserNotifications` framework requires a one-time prompt (`UNUserNotificationCenter.current().requestAuthorization`); handle a denied state gracefully (still show in-app indicators; just no NSC posts).
- Per-Session mute can be a UserDefault keyed by Session UUID for now; promote to Workspace persistence (#0029) if it should travel with the layout.
