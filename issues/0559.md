# 0559 — Close Other Tabs leaves the closed Tabs' Bell Feed rows and unseen counts behind, pointing at Tabs that no longer exist

| | |
|---|---|
| **Status** | open |
| **Module** | BellFeed / Tabs |
| **Platform** | macOS |
| **First seen** | 2026-11-05 |

## Description

Closing Tabs with a Tab chip's **Close Other Tabs** removes them without cleaning up the Bell Feed. Their rows stay in the list and keep pointing at Tabs that are gone. If any of those rows were unread, the Pane and Session unseen counts stay too, along with the Sidebar badge and the `bell.badge` toolbar icon. Every other close path purges them.

The goal, from the user (2026-11-05):

> We should make it our goal to declutter the notification list as much as possible so only what is useful remains.

Split out of [#0555](0555.md), "Further decluttering". The candidate there was "entries for Tabs or Sessions that have since closed". Most of that already works. This is the gap that's left.

## Verified (main `c51a7e1b`)

These paths all call `WindowRuntime.cleanUpBellState(forTabIDs:)` (`BattyKit/Sources/BattyKit/Runtime/WindowRuntime.swift:1121`), which removes the rows and decrements the unseen counters (#0071):

- `WindowRuntime.closeTab(id:)` (`:425`, cleanup at `:430`). That includes a Tab whose process exits: `PaneView`'s `terminal.onClose` calls `AppStateStore.closeTab`.
- `closePane` (`:688`).
- `removeSession(id:)` (`:293`), from the GUI or the CLI.
- Window close: `RootWindowView` (`Views/RootWindowView.swift:242`) cleans every Tab in the Window.

This path doesn't:

- **`PaneRuntime.closeOtherTabs(keeping:)`** (`Runtime/PaneRuntime.swift:299`). It is called from `WindowRuntime.requestCloseOtherTabs` (`WindowRuntime.swift:560`) and from `confirmPendingClose`'s `.otherTabs` case (`:587`). It replaces `tabs` and releases the terminal views, and it never touches `bellFeed` or the counters.

A related view path also bypasses cleanup. When `PaneView` has no `appStore` (`PaneView.swift:221`, `:297`, `:680`), it falls back to `pane.removeTab(id:)` directly. That only happens in previews and tests, but note it in the plan.

## Expected behavior

Close Other Tabs removes the closed Tabs' Feed rows and decrements the unseen counters exactly as `closeTab` does. The kept Tab's rows are untouched. #0297 and #0523 records are not touched.

## Recommended default

Call `cleanUpBellState(forTabIDs:)` with the closed Tab ids in `WindowRuntime` before `pane.closeOtherTabs(keeping:)`, on both call sites. Or, better, route both through one `WindowRuntime.closeOtherTabs(paneID:keepingTabID:)` so the next caller can't miss it. Keep `PaneRuntime` free of Feed knowledge, as `removeTab` is.

## Tests

Use non-default fixtures:

- Unread rows on two victim Tabs and on the kept Tab.
- After Close Other Tabs, only the kept Tab's row remains, and the Pane and Session counters equal the kept Tab's count.
- The same through the confirmation path (`confirmPendingClose`) with a busy victim.

See `BellFeedCleanupTests` and `AppStateStoreClosePaneTests` for the existing pattern.
