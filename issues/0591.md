# 0591 — Cancel in a background sheet undoes a withheld image that arrived while the sheet was open

| | |
|---|---|
| **Status** | open |
| **Module** | Projects / Pane / Tabs / Session |
| **Platform** | macOS |
| **First seen** | 2026-11-12 |

## Description

Carved out by the #0590 review (`issue/0590`; see its `## Plan` decision 4 and `## Review`). **Fix this only after #0590 is merged.** Low severity.

A background sheet (Session, Pane or Tab) snapshots the level's values and pending state when it opens. If a withheld image finishes downloading while the sheet is open, it lands on the still-pending level. Cancel then restores the open-time snapshot, which has no image path, so the arrived image is undone at that level. If the sheet was edited first, the edit ends pending, the arrival skips the level, and Cancel puts pending back with no path. Reopening the Project fixes it.

## Expected

Cancel doesn't undo an image that arrived while the sheet was open. Options: merge the arrival into the sheet's snapshot, or reapply arrivals for still-pending levels after Cancel.
