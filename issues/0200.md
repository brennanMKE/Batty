## Description

UI test `BattyUITests.TabChipRenderingTests.testDefaultTabHasNonEmptyChipTitle` (`BattyUITests/TabChipRenderingTests.swift:119`) fails with:

```
XCTAssertTrue failed - At least one tab chip must be visible on cold launch
```

This test was created by [[0164]] as part of the UI test automation suite. The test was previously masked by the `Thread.sleep` runloop-blocking bug fixed in [[0170]] — the failure is now visible on every test run.

## What to investigate

Open `BattyUITests/TabChipRenderingTests.swift:119` and trace what state the assertion is checking. Cross-reference [[0164]] for the test's design and acceptance criteria.

The failure is one of:

- **App bug** — the behavior the test asserts on is genuinely broken; fix the app.
- **Test bug** — the test's assertion, setup, or accessibility-identifier expectation is wrong; fix the test.
- **Test infra gap** — a required driver intent or accessibility identifier referenced by the test doesn't exist yet; add it.

Look at the lines around `:119` and at the driver script (if any) in the test's launch call to determine which.

## Root cause

Same as [[0202]]–[[0205]]: the parent SlidingTabBar's
`.accessibilityIdentifier("tab-bar.\(pane.id…)")` propagated to its
children, swallowing every chip's `tab-chip.<title>` identifier. On
cold launch a default chip was rendered, but the test's
`BEGINSWITH 'tab-chip.'` predicate found nothing because every chip's
identifier had been overwritten by the parent's `tab-bar.<uuid>`.

Latent since `a5d71c7` ([[0122]] BattyKit reorg) — masked by [[0170]]'s
`Thread.sleep` and then by the UI test runner being killed by
AppleSystemPolicy until that was unblocked by `scripts/run-ui-tests.sh`
(commit `51acf65`).

## Fix

Resolved by commit `e7beeb5` (see [[0205]]). One-line change in
`BattyKit/Sources/BattyKit/Views/PaneView.swift`:
`.accessibilityElement(children: .contain)` on the tab bar.

Verified locally with `scripts/run-ui-tests.sh
BattyUITests/TabChipRenderingTests/testDefaultTabHasNonEmptyChipTitle`
— test passes.
