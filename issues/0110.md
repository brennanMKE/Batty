## Description

Tier 1 localization target. Strong macOS / iOS developer community in DACH (Germany, Austria, Switzerland). German users are also notoriously meticulous bug reporters — shipping German early surfaces layout regressions fast.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `de` translation, reviewed by a native speaker.
- Launching Batty with macOS Language & Region set to Deutsch shows the full UI translated.
- Visual sweep specifically for **string-length expansion** — German is typically 30–40% longer than English. Settings labels, alert buttons, and menu items are the highest-risk surfaces for clipping or wrapping.
- `## Files changed` in the resolution should list the `.xcstrings` diff.

## Notes

- Watch for compound-word length explosions in Settings (e.g. "System notifications" → "Systembenachrichtigungen"). Consider abbreviated forms where layout breaks; flag any layout fixes as a follow-up issue if Settings panes need restructuring.
- Use the formal "Sie" address by default — Apple's convention for German macOS UI; switching to "du" reads as informal / consumer-app-ish.
- Sparkle ships German strings.
