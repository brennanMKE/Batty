Nostromo / MU-TH-UR

True amber-phosphor monochrome — P3 ffb000 on near-black, every slot a step on one amber ramp. The catalog has amber accents but no amber CRT.

The deliberate opposite of the neon candidates: one hue, sixteen values. Errors read as hotter orange rather than red, which is exactly how a 1979 terminal would have shown them. The companion is sepia on cream — the printout, not the screen.

Batty stores the global theme per appearance (co.sstools.Batty.themeName.dark / .light) and re-applies on system appearance change, so each theme ships a companion. Light companions follow the TokyoNight Day slot convention: slot 0 is a near-background tint, slot 15 is the ink, and slots 9–14 repeat 1–6 rather than brightening.
