## Description

Define the on-disk shape of `~/Library/Application Support/Batty/workspace.json` (Concepts → Workspace) so all of M7 can build on a stable schema.

**Acceptance criteria:**
- A top-level `Workspace` Codable type captures:
  - Ordered list of `WindowState` (frame, zoom, selected sessionID, sidebar collapsed flag).
  - For each Window, ordered list of `SessionState` (id, title, optional icon/color, focusedPaneID, the `SplitNode` tree).
  - For each Pane: ordered TabState list, activeTabID.
  - For each TabState: id, title override, surfaceID, last-known cwd, last-set title, unseenBellCount, bellCount, lastBellAt, lastBellMessage.
  - Bell Feed history (capped, see #0025).
- `JSONEncoder.encode(workspace)` and `JSONDecoder().decode(Workspace.self, from:)` round-trip without loss in `BattyTests`.
- Schema includes a `schemaVersion: Int` so future migrations are tractable.

## Notes

- Don't include any libghostty handles or runtime-only state. Everything serialized must be plain values.
- Keep the JSON format human-readable (`outputFormatting = [.prettyPrinted, .sortedKeys]`) — the user might inspect or hand-edit it.
- This issue is **schema only**: writing and reading the file are #0030 and #0031.

## Root cause

Persistence had no canonical on-disk shape. Without one, #0030 (save) and #0031 (load + recovery) would have to invent their own and likely diverge.

## Fix

Added `Batty/Workspace.swift` with four types and the JSON encoder/decoder configuration:

- `Workspace` — top-level container. `schemaVersion: Int` (current = 1) for future migrations, `windows: [WindowState]`, `bellFeed: [BellFeedEntry]`.
- `WindowState` — id, optional `WindowFrame`, `isZoomed`, `sidebarCollapsed`, `selectedSessionID`, `sessions: [Session]`. Precondition that `sessions` is non-empty; `selectedSessionID` defaults to the first session.
- `WindowFrame` — plain x/y/width/height. Optional on `WindowState` because newly-created windows haven't been positioned yet.
- `BellFeedEntry` — id, timestamp, the full container chain (windowID, sessionID, paneID, tabID, surfaceID), optional message body for OSC 9, `seen: Bool`.

`Workspace.empty()` produces a coherent default (one window, one session, one pane, one tab, no bells) — this is the fallback shape that #0031 will use when `workspace.json` is missing or corrupt.

`Workspace.prettyEncoder` and `Workspace.decoder` are the canonical encoder/decoder pair used everywhere persistence touches JSON. Pretty-printed with sorted keys for human-readability; ISO 8601 for dates.

`Workspace.recordBell(_:)` is the canonical bell-feed insert helper: prepends the entry at index 0, trims the tail to `Workspace.bellFeedCap = 200`. The cap is enforced here rather than on read so the file can't grow unbounded.

## Files changed

- `Batty/Workspace.swift` — new, 4 types + Workspace extension with empty/encoder/decoder/recordBell.
- `BattyTests/WorkspaceTests.swift` — new, 6 tests covering JSON round-trip, empty workspace, default selection, the bell feed cap at +50 over limit, and schemaVersion persistence.

## Gotchas

- **Sendable conformance is automatic** because all stored properties are themselves Sendable value types (UUID, Int, Bool, Double, String, Date, Optional, Array of Sendable, plus our own Sendable types). No explicit annotations needed beyond the conformance declaration.
- **`Session` is referenced from another file in the same target.** SourceKit (without Xcode build context) reports `Cannot find type 'Session' in scope`; this is LSP noise. The actual `xcodebuild` build resolves it correctly because both files are in the `Batty` target.
- **Bell feed cap is enforced on write, not read.** If a future migration changes the cap, the file may temporarily exceed it on read, but the next `recordBell` call will trim it. Acceptable.
- **Date encoding uses ISO 8601** rather than the default reference-date double for two reasons: human-readable in the file, and stable across TimeZone changes. If a future test depends on byte-exact JSON, ISO 8601 is also more deterministic than the default.
