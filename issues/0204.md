## Description

UI test `BattyUITests.TabRenameTests.testRenameWinsOverHomeDirTilde` (`BattyUITests/TabRenameTests.swift:66`) fails with:


## Root cause

Same as [[0205]]: the parent SlidingTabBar's
`.accessibilityIdentifier("tab-bar.\(pane.id…)")` propagated to its
children, replacing every chip's own `tab-chip.<title>` identifier. The
chip element existed in the accessibility tree but couldn't be matched
by its `tab-chip.*` identifier — so `matching(identifier:
"tab-chip.HomeOverride")` found nothing even though `chipTitle` was
correctly returning `"HomeOverride"` (override winning over cwd as
intended by [[0142]]'s fix).

Latent since `a5d71c7` ([[0122]] BattyKit reorg) — masked first by
[[0170]]'s `Thread.sleep` runloop block, then by the runner-trash
problem before that was unblocked.

## Fix

Resolved by commit `e7beeb5` (see [[0205]]). One-line change in
`BattyKit/Sources/BattyKit/Views/PaneView.swift`: applies
`.accessibilityElement(children: .contain)` to the tab bar so the
parent identifier no longer overwrites children's identifiers.

Verified locally with `scripts/run-ui-tests.sh
BattyUITests/TabRenameTests/testRenameWinsOverHomeDirTilde` — test
passes.
