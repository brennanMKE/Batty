2. **`tools/build-docs-page.py`** (new; stdlib only; runs under `python3 -I`; same shape as `build-backgrounds-page.py`: argparse, `main(argv)`, writes mode 0644, importable by the self-test).
   - Usage: `python3 -I tools/build-docs-page.py [--check] [--md PATH] [--html PATH] [--snippets DIR] [--capabilities FILE]`. Defaults are `website/docs/index.md`, `website/docs/index.html` and `website/docs/snippets`, resolved from the script's location.
   - **`refresh_markers(md, snippets) -> str`.** Each `<!-- generated:<name> -->` … `<!-- /generated -->` region is replaced with a fenced block holding the file's bytes. The fence is backticks, one longer than the longest backtick run in the content and at least 3. The info string comes from the extension: `.toml`→`toml`, `.json`→`json`, `.txt`→`sh` for the `claude-code-*` commands and `text` for the prompt (a small explicit map by file name; any other name is an error). The function is idempotent. It errors (exit 2, file and line in the message) on an unclosed or nested marker, a name with `/` or `..`, a missing snippet file, or a snippet in the folder that no marker uses, so the page can't silently drop a host.
   - **`render(md) -> str`.** It converts the Markdown subset to the HTML body:
     - ATX `#`/`##`/`###` headings, with `id` slugs (lowercase, non-alphanumerics to `-`), so `#share-a-page-from-your-project` works;
     - paragraphs, with lines joined;
     - `- ` and `1. ` lists, flat with single-line items and no nested blocks;
     - fenced code with a variable-length fence, the closing fence the same length, emitted as `<pre><code>`;
     - inline `` `code` ``, `**bold**` and `[text](url)`;
     - HTML comments dropped.
     Everything is HTML-escaped and raw HTML is not passed through. A relative link ending in `.md` (no scheme) is rewritten to `.html` in the HTML only, so `cli/index.md` becomes `cli/index.html`. The first `# ` heading becomes the page header's `<h1>` and is not repeated inside `<main>`. Any other construct (tables, `>` quotes, `####`) is an error, so the subset stays honest.
   - **Page template** (constant in the script). It mirrors `website/backgrounds.html`:
     - same `<head>`: charset, viewport, `<title>Docs — Batty</title>`, description and og/twitter tags with `og:url` `https://batty.sstools.co/docs/`, and icons and stylesheet via `../assets/…` and `../css/style.css`;
     - `<body class="page">`;
     - `<header class="page-header"><a class="back" href="../index.html">← Batty</a><h1>Docs</h1></header>`;
     - `<main class="prose docs">`, with a `<p class="meta">` saying the page is generated from `index.md`, followed by the body;
     - the same footer as `backgrounds.html` (Demo, Changelog, Privacy, Report an issue) with `../` prefixes, and **no "Docs" link** (#0688 adds it).
     Prose CSS already styles `pre` (`.prose pre`), so `css/style.css` needs no change. If inline `code` needs styling, add at most a `.prose code` rule. No JS of any kind: the prompt is a plain block to select and copy.
   - **`check_verbs(md, capabilities_json) -> list[str]`** (only when `--capabilities FILE` is given). Every code span and fenced line (generated blocks included) starting with `batty ` or `batty-beta ` is matched by longest prefix against `verbs[].name`. Each `--flag` or `-x` token before a bare `--` must appear in that verb's `inputSchema.properties[*].names`. Every inline code span that looks like an MCP tool (`^[a-z]+(_[a-z]+)+$`, with the first part a known noun) must map to a verb that is not in `MCPToolCatalog.excludedVerbPaths`. Any miss is reported and exits 1. This is how AC2 and AC4 are checked mechanically.
   - **`--check`** writes nothing. It exits 1 if the refreshed `index.md` or the rendered `index.html` differs from disk, naming the file and the regenerate command. Without `--check`, it writes `index.md` (refreshed) and then `index.html`.
