## Description

**HIGH (rule violations, low blast radius).** Four independent, small violations of `docs/swiftui-observation-rules.md` outside the main-window path. Each is a few lines; they share an issue because none is worth a plan of its own.

1. **`KeyboardShortcutRecorder` hops an event-origin write into a `Task`.** `onCommit` is called from `RecorderView.keyDown(with:)` — event dispatch, no update transaction to dodge — and does `Task { @MainActor in self.binding = newBinding }`. The hop only reorders: `RecorderView` sets its own `binding` and resigns first responder synchronously, while the store write lands a turn later, so an intervening `updateNSView` (`nsView.binding = binding`) can push the old binding back for a frame. `onCommit` also captures the make-time representable and is never refreshed in `updateNSView`.
2. **`ProjectSymbolPicker` returns focus on the `isPresented` flip instead of the sheet's `onDismiss`.** The `onChange` fires while the sheet is still attached and key, so `isFieldFocused = true` targets a control that can't take focus yet. This is exactly the #0475 rule.
3. **`ProjectPickerView` reloads the Project store from its own `onAppear`.** `onPresented()` → `store.projectStore.retryLoadIfNeeded()` → `reconcileWithFile()` writes `fileState`, `projects`, `unreadableOriginal` and runs `mergeRemote()` inside the sheet's first update, invalidating the sheet, the Sidebar and the Projects menu. Guarded (no-op once loaded), so it is bounded to one write per presentation after a failed read.
4. **`ShortcutsSettingsView` holds the app-wide `ShortcutsStore.shared` in `@State`.** `@State` is for models whose lifetime the view owns; harmless today only because it's a singleton.

### 1. `KeyboardShortcutRecorder` — write synchronously from the key event

File: `BattyKit/Sources/BattyKit/Shortcuts/KeyboardShortcutRecorder.swift`.

- Add `final class Coordinator { var binding: Binding<ShortcutBinding> }` (init takes the binding) and `makeCoordinator() -> Coordinator { Coordinator(binding: $binding) }`.
- `makeNSView`: `view.onCommit = { [coordinator = context.coordinator] in coordinator.binding.wrappedValue = $0 }`. Delete the `Task`.
- `updateNSView`: first line `context.coordinator.binding = $binding`, then the existing `nsView.binding = binding` / `needsDisplay`. The coordinator write is a plain (non-observed) property, so it is legal inside `updateNSView`.
- `RecorderView.swift` unchanged: `keyDown` is event dispatch, so the synchronous store write (`ShortcutRow.bindingProxy` → `ShortcutsStore.setBinding`) happens before `binding = candidate` and `makeFirstResponder(nil)`, and no later `updateNSView` can push the old value back.

### 2. `ProjectSymbolPicker` — return focus from `onDismiss`

File: `BattyKit/Sources/BattyKit/Views/ProjectSymbolPicker.swift`.

## Rule violated

1. `docs/swiftui-observation-rules.md`, "`Task` and async work": `Task { @MainActor }` is not a safety device (#0229).
2. Same section: work that must follow a sheet's dismissal waits for `onDismiss` (#0475).
3. Same doc, `onAppear` writes are audited by what they feed back into; the #0602 directive: side effects belong in the action that causes them.
4. Same doc, "Ownership and passing rules": `@State` only for a model the view owns; app-wide stores via `@Environment` or a plain property.

## Evidence

- **Proven:** all four code paths.
- **Inferred:** the one-frame shortcut revert (1) and the lost focus (2).

## Fix direction

1. Write synchronously from the event: a `Coordinator` holding `var binding: Binding<ShortcutBinding>`, refreshed in `updateNSView` (`context.coordinator.binding = $binding`); `view.onCommit = { [coordinator] in coordinator.binding.wrappedValue = $0 }`. Remove the `Task`.
2. `.sheet(isPresented: $isPresented, onDismiss: { if returnFocusOnClose { isFieldFocused = true }; returnFocusOnClose = false })`; delete the `onChange`.
3. Move the retry into one presenting action (e.g. `WindowRuntime`/`AppStateStore.presentProjectPicker(in:)`) that every presenter calls, and remove `onPresented`.
4. `private let store = ShortcutsStore.shared`, or inject it.
