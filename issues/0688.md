# 0688 — The 1.5.0 release has no step that regenerates the agent pages, links them from the site and deploys them

## Description

Child of #0680, last in order, worked on 1.5.0 release day. #0681-#0687 land the agent pages, CLI reference, machine-readable files and skill downloads on `main` but hold them off the server. This issue makes them live: regenerate everything from the 1.5.0 Prod build, add the links, release the hold and deploy with the user's go-ahead. It also writes the release-time steps down so later releases repeat them.

## Expected behavior

1. **Regenerate** from the 1.5.0 Prod build and tag: `cli/capabilities.json` and the CLI reference (#0684), the MCP snippets (#0682), `agents.md`/`agents.html` (#0683), the skill zip, `latest` zip and Claude Code marketplace (#0687). Every generator's `--check` exits 0 afterwards.
2. **Link.** Add an "AI agents" link to the footer nav of every page (`website/index.html:97-102` and the matching footer in `demo.html`, `backgrounds.html` (via `tools/build-backgrounds-page.py`'s template), `changelog.html`, `privacy.html`, `agents.html`, `cli/index.html`), and one line on the home page pointing at `/agents.html`. The home-page line's wording is coordinated with #0671, which may already have drafted it.
3. **Release the hold.** Remove the agent entries from `website/.deploy-hold` (#0681), regenerate `sitemap.xml`/`llms.txt`/`llms-full.txt` (#0685), and run `tools/check-website-hold.py`.
4. **Deploy** with the documented rsync process (#0681), dry run first, never `--delete`, only with the user's go-ahead.
5. **Release docs.** `website/README.md` "Per-release workflow" lists, in order, the regeneration steps above for every future release. If `scripts/RELEASE.md` should reference them, that edit needs the user's confirmation (`scripts/` is restricted, `AGENTS.md`).
6. Remove the "Batty Beta only" note from the agent page if #0683 carried one.

## Acceptance criteria

1. After the deploy, `curl -sI` returns 200 for `/agents.html`, `/agents.md`, `/cli/index.html`, `/cli/index.md`, `/cli/capabilities.json` (`application/json`), `/llms.txt`, `/llms-full.txt`, `/robots.txt`, `/sitemap.xml`, `/downloads/batty-cli-skill-1.5.0.zip`, `/downloads/batty-cli-skill-latest.zip` and the marketplace JSON (#0687).
2. `cli/capabilities.json` equals `batty capabilities --json` from the 1.5.0 Prod build (ignoring nothing but formatting the generator normalizes).
3. Every link in `llms.txt` and `sitemap.xml` returns 200.
4. Every CLI verb named on the agent page exists in that Prod build's `capabilities` (#0671 criterion 2's website counterpart).
5. No rsync used `--delete`.
