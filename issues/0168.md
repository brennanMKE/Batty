# 0168 — UI test suite: fuzzy finders (Open Quickly, Command Palette)

| | |
|---|---|
| **Status** | resolved |

| **Platform** | macOS |

## Description

Two fuzzy-find surfaces — Command Palette ([[0126]]) and Open Quickly ([[0128]]) — were added late in the v1 sweep. Both have already had wiring issues ([[0150]]: missing menu entry). Both have similar flow: invoke shortcut → list appears → type to filter → arrow keys move selection → Return commits → list dismisses → action runs. They're prime for a small shared test suite.

## Regressions this suite would have caught

- [[0126]] — Command Palette wiring. Tests that `Cmd-Shift-P` opens the palette, lists actions, filters, fires the selected action.
- [[0128]] — Open Quickly wiring. Same shape for `Cmd-Shift-O` and session/tab targets.
- [[0150]] — File menu missing "Open Quickly…" item. A menu-presence test would have caught it.

## Test cases

### Command Palette — would catch [[0126]]

- **`Cmd-Shift-P` opens the palette.** Assert `command-palette.root` exists.
- **Empty filter shows the full action list.** Assert at least N rows visible (where N is a documented floor — e.g. ≥ 20).
- **Typing narrows the list.** Type "split". Assert the visible rows are a subset (e.g. 2-5) and all contain "split" in their accessibility label.
- **Arrow-down + Return fires the selected action.** Type "split horiz", arrow-down to position 0, Return. Assert a new pane appeared.
- **Escape dismisses without firing.** Type "split horiz", Escape. Assert palette gone; assert no new pane.

### Open Quickly — would catch [[0128]]

- **`Cmd-Shift-O` opens the picker.** Assert `open-quickly.root` exists.
- **List includes sessions and tabs.** With 2 sessions × 3 tabs each, assert ≥ 8 rows (2 sessions + 6 tabs).
- **Typing narrows by name.** Rename a session to "Notes", a tab to "vim". Filter by each. Assert correct subset.
- **Selecting a session jumps to it.** Select a non-active session. Assert that session becomes selected (`session-row.<name>` `accessibilityValue == "selected"`).
- **Selecting a tab activates it within its pane.** Select a non-active tab. Assert `tab-chip.<title>` carries `accessibilityValue == "active"` and the pane is focused.

### Menu entries — would catch [[0150]]

- **File menu contains "Open Quickly…".** Assert `menu.file.open-quickly` exists.
- **View / Session / wherever Command Palette is menu'd contains its entry.** Assert the right menu item.
- **Each menu entry's shortcut matches the documented binding.** Assert `Cmd-Shift-O` / `Cmd-Shift-P` shown in the menu item.

## Accessibility identifiers needed

- `command-palette.root`, `command-palette.filter-field`, `command-palette.row.<action>`.
- `open-quickly.root`, `open-quickly.filter-field`, `open-quickly.row.<target>`.
- `menu.file.open-quickly`, plus the Command Palette menu path identifier.
- `accessibilityValue("selected" / "unselected")` on `session-row.<title>`.
- `accessibilityValue("active" / "inactive")` on `tab-chip.<title>`.

## Driver intents needed (from [[0158]])

- `openCommandPalette` / `closeCommandPalette`.
- `openOpenQuickly` / `closeOpenQuickly`.
- The arrow-key / Return / Escape can be driven via `XCUIApplication.typeKey(...)` directly — no driver intent needed.

## Out of scope

- Fuzzy-match algorithm tuning (separate concern; belongs in unit tests of the fuzzy matcher).
- Recent-actions ranking inside the palette (no specific regression history).
- Drag-and-drop into the palette (not a feature).

## Acceptance criteria

- All test cases pass under `xcodebuild -scheme 'Batty (Beta)' -destination 'platform=macOS' test`.
- The menu-entry test runs against both palettes and would have caught [[0150]] directly.

## Notes

- Depends on [[0158]].
- The "≥ N rows" assertions are floors, not exact counts — the visible action set grows as features land. Hard-coding exact counts would create churn.
