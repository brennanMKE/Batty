# 0139 — Per-session theme override from sidebar context menu

| | |
|---|---|
| **Status** | open |
| **Module** | Theme / Session |
| **Platform** | macOS |
| **First seen** | 2026-05-19 |

## Description

Each session should support an optional local theme override. When a session has a local theme set, switching to that session applies that theme instead of the global active theme. Sessions without a local override continue to show whatever the global theme is. The override is set and cleared via the session sidebar row's context menu.

## Expected behavior

- Right-clicking a session row in the sidebar shows a context menu with a "Set Session Theme…" item and, when a local theme is already set, a "Clear Session Theme" item.
- "Set Session Theme…" opens a compact theme picker (reuse `ThemeSelectorView` or a trimmed variant) anchored to the sidebar row or presented as a popover.
- When the user picks a theme, it becomes the local override for that session.
- Switching to a session with a local override applies that theme live (the same way the global selector does via `store.applyThemeToAllSurfaces`).
- Switching away does NOT change the global theme — the override is session-local and transient.
- "Clear Session Theme" removes the override; switching to the session then falls back to the global theme.
- Local overrides are stored in the session model (not persisted to disk — they reset on launch, keeping the persistence model simple for v1).

## Actual behavior

No per-session theme concept exists. All sessions share the global active theme at all times.

## Notes

- The session sidebar row context menu is in `SessionSidebarView.swift`. Add the new items alongside any existing context-menu actions.
- The theme override should live as an optional property on `SessionRuntime` (or its underlying model). On session focus change, check for a local override before applying the global theme.
- `store.applyThemeToAllSurfaces(_:)` applies a theme to the currently active session's surfaces. The per-session override should apply only to the surfaces belonging to that session (already the case if `selectedSession` is set to the target session before calling).
- Consider whether the override should apply immediately when set, or only on next focus switch. Applying immediately is simpler and more responsive.
- The global "Open Theme Selector" (Cmd-Shift-T) and Theme menu always operate on the global theme; the per-session override does not affect those controls.
