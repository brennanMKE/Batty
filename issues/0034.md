## Description

A native macOS Settings window (`Settings { ... }` scene) for the per-user preferences enumerated in `Concepts.md` → Settings.

**Acceptance criteria:**
- `Settings { ... }` scene is added to `BattyApp`. Cmd-, opens it.
- Tabs (or a single pane if simpler):
  - **General** — default shell (auto-detected, overridable), confirm-on-close-with-running-processes toggle.
  - **Appearance** — font family + size, cursor style (block/bar/underline; static/blinking), theme picker (mirrors View → Theme).
  - **Notifications** — bell sound on/off, system notifications on/off.
- Every setting persists to `UserDefaults` and is observed live by the app (no restart required).
- Default shell auto-detection: `$SHELL` env var → `getpwuid(getuid())->pw_shell` → `/bin/bash` fallback.

## Notes

- Per-Session bell mute is a Session-scope setting (#0028); not a global Settings pane entry.
- Paste confirmation strictness is #0035 — the toggle (and its enum) belongs in the Settings General pane.
- Keep the UI sparse — this is a tool, not a configurator.
