## Description

#0486 added a filter field to the Process Status Pane's "Pick a Running Process…" popover and a third target, `.followingName`, that re-resolves a process name whenever the shown process exits. It was developed on `issue/0486` from `release/1.2` under a user-authorized exception and landed there as `814a3182` (`#0486 Process Status picker: filter by name or PID, and follow a process by name across restarts`), for 1.2.1. #0486's Release section and Resolution notes name a separate port to `main` as the one dangling follow-up. This is that port.

`main` (at `673c6530`) has none of it: no `ProcessPickerFilter.swift`, no `RunningProcessPickerView.swift`, no `Target.followingName`, no `RunState.waiting`, and the picker is still the plain `List` #0486 describes.

The source issue is not on `main`; read it with `git show release/1.2:issues/0486.md`.
