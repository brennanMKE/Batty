## Description

Write `docs/notifications.md` to document Batty's notification pipeline: how a `\a` BEL becomes a desktop notification, sidebar badge, chip dot, and bell-feed entry; how the unseen counts cascade; how mute and auto-clear work.

Depends on `#0076` (which creates the `docs/` folder).

## What `docs/notifications.md` must cover

### 1. User-facing summary

- Three signals fire when a terminal bell rings:
  1. A chip's unseen-bell dot (`BattyTabChip.hasUnseen`).
  2. A sidebar session badge with the unseen count.
  3. A macOS desktop notification (banner / Notification Center), gated by Settings → Notifications → "Show system notifications" AND not per-session muted.
- Bell-feed popover (`Cmd-Shift-N`) shows every recorded bell with timestamp, session/pane/tab, and an optional message body. Click an entry to jump to its tab.
- Per-session mute toggle via sidebar right-click → "Mute Notifications" (per `#0068`). Suppresses desktop notifications; sidebar/chip indicators still update.
- "Mark All Bells Seen" menu item clears every unseen count.

### 2. Trigger sources

Two kinds of "bell" events:

- **Plain `\a` BEL** — emitted by any shell or process. Fires via libghostty's `terminalDidRingBell()` callback (`TerminalSurfaceBellDelegate`), which increments `terminal.bellCount` and sets `terminal.lastBellAt`.
- **OSC 9 / OSC 777 desktop notification** — apps that want a rich notification can emit OSC 9 (iTerm2 style) or OSC 777 (rxvt-unicode). libghostty's `TerminalSurfaceDesktopNotificationDelegate` reports title + body; `terminal.lastDesktopNotificationAt/Title/Body` update.

Both paths flow through `TabRuntime` observers wired in `PaneView` and into `AppStateStore`'s bell routing.

### 3. The bell-feed pipeline

```
libghostty BEL                                  libghostty OSC 9/777
       │                                              │
       ▼                                              ▼
TerminalViewState.bellCount++          TerminalViewState.lastDesktopNotificationAt
       │                                              │
       │ (PaneView.onChange)                          │ (PaneView.onChange)
       ▼                                              ▼
TabRuntime.recordBellTickIfNeeded     TabRuntime.recordDesktopNotificationIfNeeded
       │                                              │
       │ (returns delta)                              │ (returns Bool fired)
       ▼                                              ▼
AppStateStore.recordBellTick    AppStateStore.recordDesktopNotification
       │                                              │
       ├──► BellFeedEntry recorded ──────────────────►├──► BellFeedEntry recorded
       ├──► propagateUnseen (if non-focused)          ├──► propagateUnseen (if non-focused)
       └──► postNotification (gated on mute)          └──► postNotification (gated on mute)
                                                              │
                                                              ▼
                                                      BellNotifying.post
                                                              │
                                                              ▼
                                                      UNUserNotificationCenter
```

Document this flow as ASCII art or prose. Cross-reference the methods on `AppStateStore.swift`.

### 4. The "is the user looking at this tab right now" gate

- `AppStateStore.locate(tabID:)` computes `isFocused` as `session.id == selectedSessionID && tree.focusedPaneID == pane.id && pane.activeTabID == tab.id`.
- When `isFocused == true`, the bell is recorded into the feed but `propagateUnseen` is skipped — no chip dot, no badge.
- When `isFocused == false`, the unseen counts on tab/pane/session all increment.
- `postNotification` fires regardless of focus, but gated on the session's mute flag.

### 5. Auto-clear when the user visits a tab

Per `#0069`:

- `AppStateStore.markActiveTabSeen()` runs on:
  - `selectedSessionID` change (`SessionDetailView.onChange`).
  - `session.tree.focusedPaneID` change.
  - `pane.activeTabID` change (`PaneView.onChange`).
- Walks `bellFeed.entries`, marks any matching the now-active tab as `seen`, decrements aggregates.
- Also zeroes any residual `tab.unseenBellCount` to handle entries that were evicted from the feed's 200-entry cap before being marked seen.

### 6. Auto-cleanup when a tab/pane/session closes

Per `#0071`:

- `BellFeedStore.removeEntries(matchingTabIDs:)` purges entries for closed tabs.
- `AppStateStore.cleanUpBellState(forTabIDs:)` decrements unseen aggregates for each unseen purged entry.
- Wired into both `closeTab(id:)` (single tab) and `removeSession(id:)` (union of all tab IDs).
- Result: the feed never shows entries pointing at non-existent tabs; aggregate counts stay in sync.

### 7. Per-session mute

Per `#0068`:

- `SessionRuntime.notificationsMuted: Bool` — observable, defaults to `false`.
- Toggled via sidebar right-click → "Mute Notifications" / "Unmute Notifications".
- `AppStateStore.postNotification(for:at:)` early-returns when the session is muted.
- The bell-feed entry is STILL recorded and the unseen badge STILL updates — only the desktop notification is suppressed.
- Sound: libghostty plays bell sound internally and there's no app-level gate (v1 limitation).
- Persists to `LayoutModel.Session.notificationsMuted` via the Codable schema. Currently a write-only field since `#0055` defaults workspace restore to off; will activate when an opt-in restore feature lands.

### 8. Settings

`SettingsView` → Notifications pane:

- "Play sound" toggle — controls libghostty's bell sound. Stored in `SettingsPreference` UserDefaults.
- "Show system notifications" toggle — controls whether desktop notifications fire. Stored in `SettingsPreference`.
- Help row: "Per-Session mute lives on the Session row's right-click menu." (Accurate as of `#0068`.)

### 9. Bell feed UI

- Triggered by `Cmd-Shift-N` (or toolbar bell button on `SessionDetailView`).
- `BellFeedView` lists `BellFeedEntry`s in reverse chronological order.
- Unseen entries highlighted; seen entries dimmed.
- Click an entry: `AppStateStore.jumpToBellEntry(_:)` selects the session, focuses the pane, activates the tab, and marks the entry seen.
- "Mark All Bells Seen" menu item: `AppStateStore.markAllBellsSeen()` flips every entry to `seen` and zeros every aggregate.
