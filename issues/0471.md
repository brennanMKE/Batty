# 0471 — There is no Project model or store, so a Project cannot be saved to or loaded from projects.json

| | |
|---|---|
| **Status** | open |
| **Module** | Projects / Persistence |
| **Platform** | macOS |
| **First seen** | 2026-10-12 |

## Description

Projects (#0469) needs Codable value types for a Project, and a store that loads and saves them in a per-variant `projects.json`. This issue adds both, with no UI. The store must never be constructed, and the file never opened, read or created, while `FeatureFlags.projects` (#0470) is off.

## Expected behavior

**Model.** Pure value types (`Codable, Sendable, Hashable`), no view or libghostty types, next to the other layout value types in `BattyKit/Sources/BattyKit/Model/` (`LayoutModel.swift` holds `SplitDirection`/`Pane` today). Suggested shape (the implementer may refine names; the content is binding):

- `Project`: `id: UUID`, `name: String`, `rootPath: String` (absolute, standardized), `color: SessionColor` (or its stable raw value; the ten-color palette in `Runtime/SessionColor.swift`, **not** the design's six hex swatches; see #0469 "Design vs. code" 1), `layout: ProjectLayout`, `runStartupCommandsOnOpen: Bool`, `approvedCommandsHash: String?` (written by #0473's trust sheet), optionally `lastOpenedAt: Date?` for picker ordering.
- `ProjectLayout`: a **topology**, not a `PaneLayout` case, so captured arrangements (#0476) and presets share one representation. A recursive Codable node (e.g. `indirect enum ProjectLayoutNode { case pane(ProjectPane); case split(direction: SplitDirection, children: [ProjectLayoutNode]) }`, or a binary `first/second` form that mirrors `SplitTreeNode`). It stores **no ratio, size or geometry** (#0371's clarification, and #0469). It also records which preset it came from (`preset: PaneLayout?`, `PaneLayout` is `String`-backed, `Model/PaneLayout.swift:9`) so the editor can highlight the right Layout thumbnail.
- `ProjectPane`: `kind: PaneContentKind` (`BattyXPCCore/PaneContentKind.swift:28`, already Codable with its wire raw values), `tabs: [ProjectTab]` (Terminal only; at least one for a Terminal Pane), `repositoryPath: String?` (Git Status only, relative to root).
- `ProjectTab`: `title: String?`, `workingDirectory: String` (relative to root, `"."` = root), `startupCommand: String?`.
- A pure function that derives a `ProjectLayout` from each `PaneLayout` preset with `.terminal` panes (or a given kind per slot), with slot order matching `PaneLayout.layoutPanes` (`PaneLayout.swift:56-125`), so the editor's thumbnail index and the topology slot index agree. #0472 consumes this.
- Pure helpers the later children need: `paneCount`, `tabCount`, `startupCommands` (ordered list with pane/tab position, used by the picker summary "N panes · N tabs · N startup commands" and by #0473's hash), and **path resolution**: resolve a relative path against `rootPath`, rejecting (returning nil for) anything that escapes the root after standardization (`..`), so a hand-edited file can't point a Tab outside the Project silently.
- **Decoding policy**: unknown future fields ignored; a missing or unknown `kind` should **fail that Project's decode** (and log), not silently become `.terminal`. Note `Pane`'s lenient decoder in `LayoutModel.swift` decodes a missing kind to `.terminal`, so don't reuse that behavior by accident (#0371 Gotchas). One bad Project must not drop the others: decode per element.

**Store.** `ProjectStore` (`@MainActor @Observable final class`) modeled on `SessionNameCache` (`Model/SessionNameCache.swift:51-215`):

- File: `~/Library/Application Support/<Batty|Batty Beta>/projects.json`, the directory resolved through `SessionNameCache.resolvedDirectoryName(bundleIdentifier:)` (`:93-102`, the per-variant split from #0279), so Prod and Beta never share a file. Top-level `{ "version": 1, "projects": [...] }`.
- Injectable `fileURL` and `FileManager` for tests (`docs/isolate-userdefaults-in-tests.md` spirit). Tests never touch the real Application Support directory.
- Atomic writes: temp sibling then `replaceItemAt`, falling back to `moveItem` (`SessionNameCache.swift:209-216`).
- API: `projects` (ordered), `project(id:)`, `project(named:)` (case-insensitive exact match, used by the CLI), `upsert(_:)`, `delete(id:)`, `reorder`, and save. Saves happen on explicit user actions only (Save in the editor, Save as Project, trust-sheet approval), so **write synchronously on each mutation** rather than copying `SessionNameCache`'s `Task.sleep` debounce (`:153-161`). That keeps tests free of waits. If a debounce is kept anyway, it must be driven by an injected clock/scheduler per `docs/async-test-seams.md`.
- Name uniqueness: names are unique case-insensitively (the CLI opens by name). `upsert` rejects or the editor disambiguates; pick one and test it.
- Load errors (corrupt JSON) log and start empty, but **never overwrite** the corrupt file until the user saves; and when it does, keep a `projects.json.bak` of the unreadable original first.

**Flag gate.** `AppStateStore` exposes `projectStore: ProjectStore?`, constructed only when `featureFlags.projects` is true (#0470), lazily on first use or at init. With the flag off it is `nil` and nothing in the app references the file path. Append this gate site to #0470's list.

## Acceptance criteria

- Round-trip unit tests: a Project with every Pane kind, a Terminal Pane with multiple Tabs (titles, nested working directories, commands, nil command), a Git Status repository path, and a topology nested at least two levels deep.
- Each `PaneLayout` case converts to a topology whose slot count equals `paneCount` and whose slot order matches `layoutPanes`. One test per case (or a parameterized test over `PaneLayout.allCases`).
- Path resolution: `"."` → root; `"src/app"` → root/src/app; `"../x"` and an absolute path outside root → nil.
- Decoding: a file with one Project whose `kind` is unknown loads the other Projects and logs; a missing `kind` does not become `.terminal`.
- Store: upsert/delete/reorder persist through a fresh `ProjectStore` on the same temp `fileURL`; the write is atomic (no partial file on a thrown encode, tested through an injected `FileManager` or by asserting the temp-then-replace call order); a corrupt file yields an empty store, and is preserved as `.bak` on the first save.
- Per-variant path: `ProjectStore`'s canonical URL resolves to `Batty Beta/projects.json` for the Beta identifier and `Batty/projects.json` for Prod (mirrors `SessionNameCacheTests`).
- **Inertness**: with `FeatureFlags(projects: false)`, constructing `AppStateStore` and exercising session creation leaves `projectStore == nil`, and no file appears at the injected path.
- No sleeps, polling, or elapsed-time assertions in tests (`AGENTS.md` "Asynchronous tests").
- `./build.sh unit` passes with the new tests visible in the output.

## Notes

- `SessionNameCache` is the precedent #0172 explicitly kept (`issues/0172.md`); see #0469 Notes for why `projects.json` sits on the same side of that line.
- `PaneContentKind.isSingletonPerSession` is designed but unbuilt (`PaneContentKind.swift:43-60`); a Project may contain two Panes of the same non-terminal kind. Don't police it here; #0472 decides what happens at open.
- No `viewOptions` such as `pid` are stored: `.processStatus` follows the split-source Pane's active Tab when no pid is given (`Model/SplitTree.swift:345-355`), which is the right default for a freshly opened Project.
