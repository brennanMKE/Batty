# 0023 — Drag-over highlight on the target Pane

| | |
|---|---|
| **Status** | open |
| **Module** | DragDrop |
| **Platform** | macOS |
| **First seen** | 2026-05-08 |

## Description

Visual feedback while a drag is hovering over a Pane: a subtle accent border (or inset glow) on the target Pane to confirm the drop will land here. Removed on `draggingExited` and `performDragOperation`.

**Acceptance criteria:**
- During a drag with file URLs over a Pane, the Pane shows a clear "I'll accept the drop" highlight.
- The highlight disappears immediately on drop or cancel.
- Highlight does not interfere with rendering (no flickering, no resize jitter).
- Multiple Panes during the same drag (e.g. moving the cursor across split borders) hand off the highlight cleanly.

## Notes

- Implementation can be a CALayer border overlay added/removed in `draggingEntered`/`draggingExited`, or a SwiftUI overlay driven by an `@State` from the NSView via a delegate. Either is fine.
- Match the system accent color for consistency.
- If the drag has no `.fileURL` types, don't show the highlight — saves the user from a misleading affordance for unsupported drags.
