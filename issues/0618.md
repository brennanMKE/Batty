## Description

**Doc-only.** `AGENTS.md` tells every agent "`@Observable` notifies on every write, including equal-value writes." On this toolchain that is false for `Equatable` properties: the `@Observable` setter checks `shouldNotifyObservers` and skips an equal write. `docs/swiftui-observation-rules.md` ("Which equal writes notify depends on the property's type") states the correct rule, and `BattyKit/Tests/BattyKitTests/ObservationEqualWriteSemanticsTests.swift` pins all four cases (`equalWriteToEquatablePropertyDoesNotNotify`, `reassigningSameInstanceToClassReferenceDoesNotNotify`, `nonEquatableStructNotifiesOnEveryWrite`, `nilToNilOnOptionalClassReferenceNotifies`). Several code comments repeat the wrong claim as the reason a guard exists. The guards themselves are still right — the rules doc keeps store-level idempotence because it stops a re-asserted mutator's *other* side effects — only the stated reason is wrong. Agents read `AGENTS.md` first, so the wrong rule there mis-steers every audit and plan (it was the premise of a constraint in #0604).

Already correct (no change): `docs/swiftui-observation-rules.md:92-105`, `docs/themes.md:415`, `Theme/ThemeChrome.swift:26-30`, `Runtime/AppStateStore.swift:1146-1148`.

## Expected

- `AGENTS.md` states the type-dependent rule in one sentence and points to `docs/swiftui-observation-rules.md` and `ObservationEqualWriteSemanticsTests`: equal writes to `Equatable` properties and same-instance class references don't notify; non-`Equatable` values, `nil`→`nil` on optional class references, and in-place mutations (`array.removeAll {}`, `dict[k] = v`, `entries[i].x = y`) always do. Keep store-level idempotence guards for their side effects.
- Each listed comment gives the real reason for its guard (skipping side effects, an in-place mutation, or simply idempotence), or is deleted if the guard is self-explanatory. No code behavior changes.

## Rule

- `AGENTS.md` itself: no comments that state false invariants; grep every factual claim in a comment.
- swift-guidance `swiftui-observation.md` (toolchain override: equal writes to `Equatable` `@Observable` properties do not notify).
