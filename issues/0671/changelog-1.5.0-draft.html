1.5.0 — YYYY-MM-DD

Coding agents can drive Batty: they know which Pane they are in, set up from Settings, run commands and dev servers, and share pages on your tailnet.

New

  • Agents know they are in Batty. batty agent context names the Session, Tab and Pane, and the Claude Code SessionStart hook and the MCP server's instructions say the same (#0661, #0662, #0663).
  • Set up the MCP server and agent guidance for Claude Code, Codex, Cursor and OpenCode from Settings → Advanced → Command Line and AI Agents, with a preview first. Codex is now registered too (#0665, #0666, #0669).
  • Copy Prompt gives your agent a prompt to add a Batty section to its own global instructions (#0664).
  • batty tab new opens a Tab, and --wait on tab new and pane split waits for a command and reports its exit status (#0667, #0668).
  • A Servers list in the toolbar, with batty server start, share, list, stop, restart and unshare (#0691, #0692).
  • batty server serve serves a folder with PhotonHTTP, if installed (#0693).
  • Share a server on your tailnet from its row or with batty server tailnet (#0694).
  • A new Help page, AI Agents and Servers (#0671). See the command-line docs.

Improvements

  • The Web Preview Pane and server preview are gone; agents look at pages with a webdriver such as safaridriver (#0690).
