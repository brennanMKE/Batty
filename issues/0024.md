## Description

Detect bell events at the surface level and convert them to per-Tab events. Two sources (PRD §6.13, Concepts → Bell event):

- **ASCII BEL (`\a`, 0x07)** — the classic bell.
- **OSC 9** — `ESC ] 9 ; <message> BEL`, the iTerm-style notification escape with an attached message.

**Acceptance criteria:**
- libghostty's per-surface bell callback is wired and fires a Swift function on every BEL.
- If libghostty exposes the OSC 9 message body, capture it as a `String?` alongside the bell.
- Each event is recorded against the originating Terminal Session: `bellCount`, `lastBellAt`, `lastBellMessage`.
- Hook installation is idempotent and surface-scoped (registering twice for the same surface doesn't double-fire).
- Manually verified: running `printf '\a'` in a shell triggers a bell event; `printf '\033]9;hello\a'` triggers a bell with `lastBellMessage == "hello"`.

## Notes

- **API discovery is part of this issue.** The libghostty API for bell + OSC 9 needs to be confirmed against the current Doxygen / `libghostty.tip.ghostty.org` docs. If only BEL is exposed, capture that and note OSC 9 as a follow-up.
