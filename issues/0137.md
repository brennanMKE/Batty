## Description

Add a theme selector invoked by Cmd-Shift-T. It presents as a sheet (or popover anchored to the toolbar) with a live-filter text field at the top and a grid of theme cards below. Each card shows the theme's color palette swatches and its name. Selecting a theme applies it immediately (live preview); pressing Escape or clicking outside dismisses without committing.

The filter text field should work the same way as the Command Palette and Open Quickly: text typed narrows the grid in real time, matching on theme name. Arrow keys navigate the grid; Return confirms the selection; Escape cancels.

## Steps to reproduce

n/a — feature request.

## Expected behavior

- Cmd-Shift-T opens the theme selector from any window state.
- A search field is focused automatically on open.
- Typing filters the grid live (case-insensitive substring match on theme name).
- Each card shows the theme name and a set of color swatches derived from the theme's palette (background, foreground, cursor/accent, and a few ANSI colors).
- Clicking or arrowing to a card and pressing Return applies the theme (same path as the existing View → Theme menu).
- Escape dismisses without changing the active theme.
- The grid gracefully handles the full set of bundled themes plus any user themes in `~/.config/ghostty/themes/`.

## Actual behavior

No keyboard shortcut or dedicated theme selector UI exists. Themes are only accessible through the View menu, which presents a flat list with no preview.

## Notes

- Prototype the card layout and filter UI first in the Themes sandbox app (`../Themes`) before wiring into Batty. The sandbox already has `AppTheme`, `RGBColor`, and `ChromePalette` which can serve as a starting point for the card swatch math.
- The existing `GhosttyThemeCatalog` is the source for available themes. Cards should derive swatches from the theme's `background`, `foreground`, `cursorColor`, and a few palette entries (indices 0–7) — same approach used in `ChromePalette.init(theme:)`.
- The keyboard shortcut Cmd-Shift-T is currently unbound in Batty. Register it in `BattyApp.swift` commands alongside the existing Cmd-Shift-N / Cmd-Shift-D shortcuts.
- Apply / cancel behavior: on selection, call the same `AppStateStore.applyThemeToAllSurfaces(_:)` path that the View menu uses. On Escape, re-apply the theme that was active when the sheet opened.
- Consider the filter field's focus management carefully — it should auto-focus on sheet appear, same pattern as `CommandPaletteView` and `OpenQuicklyView`.
