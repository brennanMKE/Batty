## Description

Add a theme selector invoked by Cmd-Shift-T. It presents as a sheet with a live-filter text field at the top and a grid of theme cards below. Each card shows the theme's color palette swatches and its name. Selecting a theme applies it immediately (live preview); pressing Escape dismisses without committing.

The filter text field works the same way as the Command Palette: text typed narrows the grid in real time. Arrow keys navigate the grid; Return confirms the selection; Escape cancels.

## Steps to reproduce

n/a — feature request.

## Expected behavior

- Cmd-Shift-T opens the theme selector from any window state.
- A search field is focused automatically on open.
- Typing filters the grid live (fuzzy match on theme name).
- Each card shows the theme name and a set of color swatches from the ANSI palette.
- Clicking or arrowing to a card and pressing Return applies the theme.
- Escape dismisses without changing the active theme.

## Actual behavior

No keyboard shortcut or dedicated theme selector UI exists. Themes are only accessible through the Theme menu, which presents a flat list with no preview.

## Notes

- Prototype the card layout and filter UI first in the Themes sandbox app.
- The existing `GhosttyThemeCatalog` is the source for available themes.
- Apply / cancel behavior: on selection, call `AppStateStore.applyThemeToAllSurfaces(_:)`. On Escape, re-apply the theme that was active when the sheet opened.

## Root cause

No theme selector UI existed. Themes were accessible only through the flat Theme menu with no preview.

## Fix

Added `ThemeSelectorView` (620x500 sheet, `.regularMaterial` background) invoked by Cmd-Shift-T. Search field auto-focuses on open; fuzzy filtering narrows the grid in real time. `ThemeCard` renders each theme's ANSI palette colors (indices 1-6) as 10pt dot swatches. Selecting a card applies a live preview; Return commits (writes `ThemePreference.defaultsKey`); Escape restores the saved theme. `ShortcutAction.themeSelector` added with default binding Cmd-Shift-T.
