## Description

Phase 6 of the #0234 multi-window umbrella: the behaviors that only exist once two windows can be open, per `docs/multi-window-design.md` §8.

Scope:

- **Termination:** the app terminates when the last *content* window closes (Help/Settings don't count) — today's "terminate when the last session closes" generalized. Closing the last session in a window closes that window (`WindowRuntime.onAllSessionsClosed` → close window; the app delegate's terminate hook moves to last-content-window-closed). With one window this composes to exactly the current behavior.
- **Window close with live sessions:** confirm-then-teardown via `NSWindowDelegate.windowShouldClose`, prompting iff any tab in the window reports `terminal.needsConfirmClose`, honoring the existing "Confirm on close with running processes" setting (same contract as `QuitConfirmation`). `QuitConfirmation.shouldQuitOrPrompt` widens to all windows' sessions for Cmd-Q.
- **Bell-feed routing:** `BellFeedEntry.windowID` carries the real owning window's ID (retiring the throwaway `UUID()` defaults in `AppStateStore.recordBellTick`/`recordDesktopNotification`). `jumpToBellEntry` makes the owning window key and front, then runs the existing selection flow on that window's runtime — the canonical flow already specified in `Concepts.md` § Bell Feed. Dead-window entries no-op and are marked seen; bell-state cleanup on window close reuses `cleanUpBellState(forTabIDs:)`.
- `markActiveTabSeen` / `locate(tabID:)`'s `isFocused` gain the key-window term so a bell in a non-key window counts as unseen.

`makeKeyAndOrderFront` is responder-changing AppKit: legal only from event-origin handlers (feed click, notification tap), never from view-update code — `docs/swiftui-observation-rules.md` is binding here.

## Acceptance criteria

- Bell in window B while window A is key: badge increments, feed entry click brings window B forward and lands focus on the source tab; same via system notification tap.
- Closing a window with a running process prompts (setting honored); closing the last content window quits; single-window quit flows unchanged (#0217 lineage tests green).
- `scripts/build.sh unit` passes; UI suite updated and passes.
