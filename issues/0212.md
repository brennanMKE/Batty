## Description

Repoint the `libghostty-spm` Swift package dependency in `BattyKit/Package.swift` from the local fork (`https://github.com/brennanMKE/libghostty-spm` at revision `2694c40bd1b8f110ad4e6714e0ab7b04ee1f858f`) to the upstream `Lakr233/libghostty-spm` at tag `1.1.9` (commit `6ebd4bd2867f4bb8084e438dfa9a6531ad1f2ca7`). The fork's reason for existing — local changes ahead of upstream — has been merged upstream, so the fork is no longer needed and we can track upstream main directly.

This also unblocks the build, which has been broken since the fork pin (#0210) referenced a Lakr233 binary asset that was pruned (HTTP 404 at `storage.1.0.1779090382/GhosttyKit.xcframework.zip`). The upstream `1.1.9` binary at `storage.1.1.9/GhosttyKit.xcframework.zip` is live.

Resolves [[0210]]. Unblocks [[0173]], [[0174]], [[0175]], [[0178]], [[0179]], [[0180]], [[0185]], [[0186]] (all eight failing-UI-test issues whose subagents could not build).
