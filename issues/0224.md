# 0224 — Extract tab chip uniqueness tests from BattyUITests into BattyKit unit tests

| | |
|---|---|
| **Status** | open |
| **Module** | Testing |
| **Platform** | macOS |
| **First seen** | 2026-05-28 |

## Description

`BattyUITests/TabChipRenderingTests.swift` verifies that tab chip accessibility identifiers are unique per session and per renamed tab/session. The uniqueness invariant is a property of `TabTitleFormatter.chipTitle(...)` — it is pure logic with no visual component. These tests launch the full app and count accessibility elements only because no unit alternative existed.

## Fix

Add `BattyKit/Tests/BattyKitTests/TabChipUniquenessTests.swift`. Create multiple `TabRuntime` / `SessionRuntime` objects directly, call `TabTitleFormatter.chipTitle(...)` for each, and assert the resulting strings are distinct. No app launch needed.

Candidate tests to cover:
- `chipTitlesAreUniqueAcrossDefaultSessions`
- `renamedTabChipTitleDiffersFromDefaultTitle`
- `renamedSessionChipTitleDiffersFromOtherSessions`

Once the unit tests exist and pass, the corresponding cases in `BattyUITests/TabChipRenderingTests.swift` may be removed or kept as a shallow smoke-test.
