# 0595 — Background Sets grid thumbnails misalign when a cell has a status line

| | |
|---|---|
| **Status** | open |
| **Module** | Settings / Theme |
| **Platform** | macOS |
| **First seen** | 2026-11-12 |

## Description

In the Background Sets grid, a thumbnail whose caption has a second status line ("In use", "Available offline", or a download failure message) sits about 17 pt higher than its neighbours in the same row that show only a title. The cells have different heights, and `LazyVGrid` centres each cell vertically in its row, so the taller cells start higher. The user asked: "The images should line up."

The user guessed that the section title pushes the first image down. The screenshot says otherwise: only rows that contain a status line are misaligned, and rows with no status line line up. The section title is not the cause.

## Steps to reproduce

1. In Batty Beta, open the Background Images window and switch to the Background Sets tab, or open it from the Project Editor's background picker.
2. Download at least one image from a set so it shows "Available offline", and use one image in a Project so it shows "In use".
3. Look at a row that has both captioned cells and title-only cells.

## Expected behavior

- Every thumbnail image in a row starts at the same y.
- Titles line up across the row.
- A status line sits below its title and does not move the image.

## Actual behavior

Cells with a status line are taller, and the grid centres them in the row, so their images start about 17 pt higher than title-only neighbours. In "Future Cities", row 1, "Canal After Rain" (In use) and "Sky Gardens at Dawn" (Available offline) sit higher than "Skyline in the Fog", "Maglev at Dusk" and "Desert Dome". In "Cool Vehicles", "Expedition Truck…" (In use) sits higher than the rest of its row.

## Notes

Root cause (checked against the code on 2026-11-12):

- `BattyKit/Sources/BattyKit/Views/BackgroundSetsView.swift`, `setSection(_:catalogURL:)`, around lines 95-99: `LazyVGrid(columns: [GridItem(.adaptive(minimum: Self.minimumCellWidth), spacing: Self.spacing)], alignment: .leading, spacing: Self.spacing)`. The `GridItem` has no `alignment`, so each cell is centred vertically in its row. The `alignment: .leading` argument is the grid's horizontal alignment only.
- `HostedBackgroundCell.body` (around line 149) is a `VStack` of a 16:10 picture, a one-line title, and an optional `status` view. `status` is `EmptyView` while fetching, a red failure message of up to 2 lines on `.failed`, or "In use" / "Available offline". Cell height therefore varies by 0, 1 or 2 caption lines. "In use" also depends on `digest`, which loads asynchronously, so a cell can grow and shift after it first appears.

The same defect is in the My Images grid:

- `BattyKit/Sources/BattyKit/Views/BackgroundImagesView.swift`, `grid(columns:)`, around line 147: `LazyVGrid(columns: Array(repeating: GridItem(.flexible(), spacing: Self.spacing), count: columns), spacing: Self.spacing)` has no `GridItem` alignment either.
- `BackgroundImageCell` (around line 345) has a fixed 110 pt picture, then a name, a size, a uses line of 1-2 lines, and an optional shared-status line of 1-2 lines. Cells vary in height in the same way, so their pictures are vertically centred against each other too. Include this grid in the fix.

Fix direction (for the planner to confirm): top-align cells, for example `GridItem(..., alignment: .top)`, so images line up and captions hang below. Optionally reserve the status line's height so every row is the same height and a cell doesn't change height when "In use" arrives late.

Verification: this is a visual change and needs the user's sign-off. A UI test in `BattyUITests/BackgroundSetsTests.swift` could assert that the `background-sets.cell.*` elements in one row share the same `frame.minY`. The test fixture would need an "Available offline" or "In use" cell next to a title-only cell. A similar check could cover `background-images.cell.*`. UI tests run only in the Tart VM; check that they compile on the host with `./build.sh ui-typecheck`.
