# 0019 — Draggable split dividers with live ratio updates and persistence

| | |
|---|---|
| **Status** | open |
| **Module** | Split |
| **Platform** | macOS |
| **First seen** | 2026-05-08 |

## Description

Make the divider between two children of a Split draggable. Live preview while dragging; the ratio is written back into the `SplitNode` model. Mirrors `Concepts.md` → Split → "Resized by".

**Acceptance criteria:**
- Each split divider responds to mouse drag with the appropriate cursor (resize-left-right or resize-up-down).
- Dragging updates the ratio in real time; child views resize live without flicker.
- Ratio is clamped to a sensible range (e.g. 0.1–0.9) so a Pane can't be made invisible.
- The new ratio writes back to the model so it persists (M7) and survives session-switching.
- Resizes nest correctly: dragging the divider of an inner split doesn't disturb outer splits.

## Notes

- This likely requires a custom split container (not `HSplitView`/`VSplitView`) — flag if you discover SwiftUI's built-ins can do live ratio updates well enough.
- Snap-to-50%-when-near-the-middle is a nice-to-have — leave for follow-up if it complicates this issue.
- Verify drag works correctly when the window is being resized at the same time (edge case, but real with multi-monitor setups).
