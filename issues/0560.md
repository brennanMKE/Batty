## Description

`BellFeedStore.cap = 200` (`BattyKit/Sources/BattyKit/Runtime/BellFeedStore.swift:138`). `record(_:)` inserts at index 0 and evicts the oldest past the cap, whether those entries are read or not and however old they are. The Feed is in memory only, so it starts empty on every launch. `Concepts.md` (Bell Feed → Contents) and [#0514](0514.md) both cite "capped at 200 entries".

The goal, from the user (2026-11-05):

> We should make it our goal to declutter the notification list as much as possible so only what is useful remains.

Split out of [#0555](0555.md), "Further decluttering".

## What the data shows

The exported decision log (`~/Downloads/batty-bell-decisions-2026-11-05-142840.txt`) holds 188 bells across 11 days (2026-10-25 to 2026-11-05). Today that would make 181 rows, since 7 collapsed. After #0555, 89 rows would remain, about 8 a day, with a peak of 24 on 2026-10-27. Of those 89, 69 repeat an earlier row's Tab and message. [#0556](0556.md) (prune on visit) would remove most of them once read. Even before either change, a launch that runs a few days doesn't reach 200, so the cap isn't what decides what the user sees.

## Recommended default

**Keep 200 for now.** Revisit after #0555 and #0556 land, using the capture log (#0523).

- If unread rows routinely number more than about 50, the Feed has stopped being a short list. The fix then is better collapse or pruning, not a smaller cap.
- A smaller cap evicts unread rows first, which is the opposite of useful.
- If the cap does change, evict seen rows before unseen ones.
- Update `Concepts.md` and #0514's verified-facts line to match.

## Notes

- `BellFeedEntry` has no `seenAt`, so any "remove read rows after N minutes" rule needs that field first. #0556 makes it unnecessary for visited rows.
- `pruneRatingState` and `AppStateStore.scheduleSummarization`'s `summarizationTasksForTesting` pruning both run off Feed membership, so any eviction change has to keep them in step.
- The #0297 decision history has its own capacity, separate from this cap (`BellDecisionHistory`).
