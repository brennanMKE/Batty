# 0326 — docs/shortcuts.md omits twelve shortcut actions, lists two wrong defaults, and cites two moved file paths

## Description

`docs/shortcuts.md` is the document a user (or engineer) consults to learn Batty's keyboard surface, and it is currently wrong in both directions: it is missing real bindings that exist in the app, and it lists bindings that don't exist. Surfaced by #0325's review; same doc-drift class as #0321, #0324, and #0325. All claims below were re-verified against source on 2026-08-08.

**1. The catalog omits twelve of the twenty-five actions.** `ShortcutAction` (`BattyKit/Sources/BattyKit/Shortcuts/ShortcutAction.swift`) has 25 cases. The Section 2 catalog table (`docs/shortcuts.md:93-107`) lists 13. Missing, with their actual defaults from `ShortcutAction.defaultBinding`:

| `rawValue` | Display name | Actual default |
|---|---|---|
| `splitFullHeightColumn` | Split Full-Height Column | `Cmd-Option-D` |
| `splitFullWidthRow` | Split Full-Width Row | `Cmd-Shift-Option-D` |
| `commandPalette` | Open Command Palette | `Cmd-Shift-P` |
| `openQuickly` | Open Quickly | `Cmd-Shift-O` |
| `layoutPicker` | Open Layout Picker | `Cmd-Shift-L` |
| `themeSelector` | Open Theme Selector | `Cmd-Shift-T` |
| `newWindow` | New Window | `Cmd-Shift-N` |
| `exitShell` | Exit Shell | `Cmd-Shift-X` (landed by #0309) |
| `resizeSplitLeft` | Move Split Divider Left | `Cmd-Ctrl-←` (landed by #0325) |
| `resizeSplitRight` | Move Split Divider Right | `Cmd-Ctrl-→` (#0325) |
| `resizeSplitUp` | Move Split Divider Up | `Cmd-Ctrl-↑` (#0325) |
| `resizeSplitDown` | Move Split Divider Down | `Cmd-Ctrl-↓` (#0325) |

(The #0325 review reported "nine" missing actions; the verified count is twelve — the reviewer's enumeration counted the four resize actions as one entry.)

**2. Two listed defaults are wrong.** Both tables (Section 1 at lines 80–81 and Section 2 at lines 106–107) say:

- Toggle Sidebar → `Cmd-Ctrl-S`. Actual (`ShortcutAction.swift:104-105`): key `"b"`, modifiers `[.command]` → **`Cmd-B`**.
- Toggle Bell Feed → `Cmd-Shift-N`. Actual (`ShortcutAction.swift:106-107`): key `"b"`, modifiers `[.command, .shift]` → **`Cmd-Shift-B`**.

The second is actively misleading: `Cmd-Shift-N` is now the real default for `newWindow`, so a user following the doc opens a new window instead of the bell feed.

**3. Two cited file paths predate a source move.** The doc links (lines 179, 225, 413, 415):

- `../BattyKit/Sources/BattyKit/BattyShortcuts.swift` — actual location `BattyKit/Sources/BattyKit/Commands/BattyShortcuts.swift`.
- `../BattyKit/Sources/BattyKit/TabRuntime.swift` — actual location `BattyKit/Sources/BattyKit/Runtime/TabRuntime.swift`.

All other paths in the doc's "Where to look" table verify as existing.

**4. The "v1" framing does not excuse the drift.** Section 1's table is headed "Default bindings shipped in v1 (from `ShortcutAction.defaultBinding`)" — a partial defence for omitting post-v1 actions, but not for the two wrong defaults, since the table names `ShortcutAction.defaultBinding` as its source and that source now says `Cmd-B` / `Cmd-Shift-B`. Section 2's catalog has no v1 scoping at all — it opens with "The full set is `ShortcutAction.allCases`" and so reads as current and complete, which it is not. The footer ("Document version: 1 — 2026-05-12") confirms the doc has not been revised since May.

**5. Related rot-prone citation in a test comment.** `BattyKit/Tests/BattyKitTests/SplitTreeResizeTests.swift:32` contains `// … matches PRD.md:162 / the #0325 worked example …`. Verified: this is the only surviving `.md:NNN` line-number citation in any Swift file in the repo (`grep -rn '\.md:[0-9]' --include='*.swift'`). The citation happens to still be accurate today (PRD.md:162 is the keyboard-resize line), but it is exactly the rot-prone comment reference `CLAUDE.md` bans, and #0325 removed the equivalent cite from `SplitTree.swift` — this one should go the same way (drop the line number; the surrounding prose already explains the invariant).

## Expected behavior

`docs/shortcuts.md` matches `ShortcutAction.swift`: all 25 customizable actions listed with their real defaults, file links that resolve, and framing that does not present a stale snapshot as the current catalog. No `.md:NNN` line-number citations remain in Swift sources.

## Actual behavior

The catalog covers 13 of 25 actions, states two defaults that no longer exist (one of which now triggers a different action), links two files at pre-move paths, and one test comment carries a banned line-number citation.
