# 0243 — Changing the global theme does not re-theme terminal panes in any window

| | |
|---|---|
| **Status** | open |
| **Module** | Theme / Window |
| **Platform** | macOS |
| **First seen** | 2026-06-16 |

## Description

Multi-window regression: picking a new theme in the (global) theme selector no longer changes the terminal pane colors — not in the current active window, and not in the other open window. The selection appears to take (UserDefaults is written) but the live surfaces are not recolored.

## Steps to reproduce

1. Open two windows (Shift-Cmd-N).
2. Open the theme selector (Cmd-T) in the key window and pick a different theme.

## Expected behavior

Every window's terminal panes that follow the global theme immediately recolor to the chosen theme.

## Actual behavior

Neither window's terminal panes change color.

## Notes

- Root cause is the `windows[0]`-only forwarding shim. `AppStateStore.applyThemeToAllSurfaces(_:)` (the global-theme path used by `ThemeSelectorView.selectTheme`) iterates `self.sessions`, and `AppStateStore.sessions` is defined as `windows[0].sessions` (`AppStateStore.swift:200`). So only the first window's surfaces are ever re-themed. When the key window is the second window (the common case right after Shift-Cmd-N, and the picker now opens only in the key window per #0242), the surfaces the user is looking at are never touched, so it reads as "nothing changed."
- `applyGlobalThemeForCurrentAppearance()` (system Light/Dark switch) routes through the same `applyThemeToAllSurfaces`, so appearance-driven re-theming has the same one-window limitation.
- The per-session apply path (`applyTheme(_:to:)`, used by `SessionThemeSelectorView` and by `SessionDetailView`'s `applyActiveSessionTheme(for:)` on session switch) is *not* affected — it operates on the session passed in.
- `themeChrome` is a single app-wide instance shared by every `RootWindowView`, and per-window themes are out of scope (`docs/multi-window-design.md` §10), so the fix is purely to fan the surface `setTheme` calls across all windows' sessions.
- Same regression class as #0240 (Phase 7) and #0242; once #0240's UI suite can run, add multi-window coverage asserting a global theme change recolors surfaces in every window.
