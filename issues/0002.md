## Description

Add the SlidingTabs package as a dependency so the per-pane tab strip (Concepts → Tab) is available when M3 starts. We have a local checkout at `/Users/brennan/Developer/brennanMKE/SlidingTabs` and a published GitHub repo at `https://github.com/brennanMKE/SlidingTabs`.

**Acceptance criteria:**
- `import SlidingTabs` compiles in the `Batty` target.
- `SlidingTabBar` and `DefaultTabChip` resolve.
- Build still passes via `xcodebuild -scheme Batty -destination 'platform=macOS' build`.

## Notes

- Use the local-path SPM dependency to start so iteration on SlidingTabs itself doesn't require pushing tags. Switch to the GitHub URL with a version pin before shipping.
- SlidingTabs requires macOS 15+ — already aligned with `Build.xcconfig` (`MACOSX_DEPLOYMENT_TARGET = 15.6`).
- The `hasUnseen` chip dot will be wired to bell state in M6 (#0024+), not in this issue.

## Root cause

Feature gap, not a bug: M3 (Tabs) needs the SlidingTabs package available in the Batty target so `SlidingTabBar` and `DefaultTabChip` can be referenced when the Tab bar is built out.

## Fix

Added SlidingTabs as a local-path SPM dependency on `BattyKit` (the existing umbrella package) and re-exported it from `BattyKit.swift` so the Batty target picks it up transitively, matching the GhosttyKit wiring from #0001. A small smoke file in the Batty target references both `SlidingTabBar` and `DefaultTabChip` so a regression in either type would fail the build.

## Files changed

- `BattyKit/Package.swift` — added `.package(path: "../../SlidingTabs")` and the `SlidingTabs` product as a target dependency.
- `BattyKit/Sources/BattyKit/BattyKit.swift` — added `@_exported import SlidingTabs` alongside the existing `GhosttyKit` re-export.
- `Batty/SlidingTabsSmoke.swift` — new file in the Batty target referencing `SlidingTabBar` and `DefaultTabChip` via `import BattyKit`.

## Gotchas

- The local-path dependency form is intentional for now so SlidingTabs can be iterated in place without pushing tags. Switch to `.package(url:..., from:)` with a version pin before shipping.
- `SlidingTabBar<Item, Chip>` is generic over `Item: Identifiable` and `Chip: View`; the smoke file uses a small private `Identifiable` struct to satisfy the constraint while keeping the metatype reference compact.
- A local-path SPM dependency does not produce a `Package.resolved` entry, so neither `BattyKit/Package.resolved` nor the workspace's `Package.resolved` changed.
