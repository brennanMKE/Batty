## Description

Replace the M1 single-pane window shell with a `NavigationSplitView` whose leading column is the session sidebar. Multiple sessions can coexist; selecting a session swaps the detail area. New sessions are created via a "+" toolbar button and start with one Pane / one Tab / one fresh Terminal Session in the user's home directory.

**Acceptance criteria:**
- The window now uses `NavigationSplitView` with a sidebar on the left and detail on the right.
- The sidebar shows a `List` of sessions; each row shows the session title.
- A "+" button in the sidebar's toolbar creates a new session and selects it.
- Exactly one session is selected per Window. Switching sessions instantly swaps the detail area.
- Surfaces in non-selected sessions stay alive (the shell process keeps running).
