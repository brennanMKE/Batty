# 0016 — Auto-update tab title from focused surface (process → cwd → override)

| | |
|---|---|
| **Status** | open |
| **Module** | Tabs / TerminalSurface |
| **Platform** | macOS |
| **First seen** | 2026-05-08 |

## Description

A Tab's chip title resolves as: focused-surface process name → cwd basename → user-set override (first non-empty wins) — `Concepts.md` → Tab. Title updates as the user `cd`s around or runs different programs.

**Acceptance criteria:**
- Tab chip text reflects the running process inside its surface (e.g. `vim`, `bash`, `node`).
- When the surface is idle (just a shell), the title falls back to the cwd basename (e.g. `Batty`, `~`).
- A user-set title override (set via tab context menu — separate follow-up if needed) wins over both.
- Title updates within ~500ms of the underlying state changing — not instant, but not laggy.

## Notes

- libghostty surfaces emit OSC 0/1/2 title-set escapes; capture those if exposed. If only OSC is exposed, use that as the override path; cwd-tracking comes from libghostty's shell integration.
- Don't poll process state aggressively — driven updates from libghostty callbacks are preferred. If we have to poll, debounce.
- Add a tab context menu with "Rename" / "Reset title" as a follow-up if not in scope here.

## Revised approach — 2026-05-08

`GhosttyTerminal` exposes title and cwd via two delegate protocols and via `TerminalViewState` itself:

- `TerminalSurfaceTitleDelegate.terminalDidChangeTitle(_ title: String)` — fires on OSC 0/1/2.
- `TerminalSurfacePwdDelegate.terminalDidChangeWorkingDirectory(_ path: String)` — fires on shell-integration cwd reports.
- `TerminalViewState.title` — already published (`@Observable`); the SlidingTabs chip can bind directly.

**Revised acceptance criteria:**
- The tab chip displays `TerminalViewState.title` if non-empty, else the cwd basename from the pwd delegate, else the user-set override (`Tab.titleOverride`).
- A small adapter in `BattyKit` listens for `terminalDidChangeWorkingDirectory` and updates `Tab.lastKnownCWD` for persistence (#0030 cadence).
- No polling. Updates are driven by the delegate callbacks; SwiftUI re-renders the chip via the `@Observable` change.

**No more BEL-only fallback worry**: `TerminalSurfaceTitleDelegate` is on the public API, so the OSC 0/1/2 path is reliably exposed.
