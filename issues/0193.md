## Root cause

Same as [[0176]]: `TerminalPlaceholderView`'s
`.accessibilityValue('focused'/'unfocused')` didn't propagate from a
`Color.clear` root, so the `focusedIndex` helper's `.value` read
came back empty and the test never saw any pane reporting `focused`.

Latent since [[0141]] removed the enclosing `GeometryReader` when
switching to `onGeometryChange`. Masked by [[0170]] (`Thread.sleep`)
and then by the UI-test-runner kill problem.

## Fix

Resolved by code commit `a33de29` (see [[0176]]). App now uses
`.accessibilityLabel` for the focus-state string; `PaneFocusTests`
`focusedIndex` reads `.label` instead of `.value`. Verified
locally with `scripts/run-ui-tests.sh BattyUITests/PaneFocusTests`
— all 8 tests pass.

([[0176]]).
