## Root cause

The `XCTAssertTrue` at `KeyboardShortcutTests.swift:68` is the wait that
follows `Cmd-T` and polls until a second `tab-chip.*` appears — the
prerequisite for the subsequent `Cmd-W`/window-count assertion. Pre-[[0170]],
each test file's duplicated `waitFor` helper used
`Thread.sleep(forTimeInterval: 0.1)` from a `@MainActor` test method,
starving the test process's main runloop and preventing XCUITest's XPC
bridge from delivering the post-`Cmd-T` accessibility-tree snapshot inside
the 5s budget. The predicate kept reading the stale single-chip count and
the assertion failed before `Cmd-W` was ever dispatched.

The app-side Cmd-T and Cmd-W routing is correct; the second chip appears
and the window count stays equal across `Cmd-W` (which closes the tab,
not the window) well inside 5s now that the centralized `waitFor` (commit
`eb00412`) pumps the runloop via `RunLoop.run(until:)` between predicate
evaluations.

## Fix

No code change. The fix landed transitively with [[0170]]
(commit `eb00412`'s `waitFor` overhaul). This matches the resolution
pattern for the sibling issues [[0174]], [[0175]], [[0178]], and [[0179]]
in the same UI-test stabilization batch.

## Gotchas

- The final assertion is `XCTAssertEqual(app.windows.count, windowCountBefore)`
  — it confirms `Cmd-W` did **not** close the window, but it does not
  assert that the tab count *decreased*. A regression where `Cmd-W` becomes
  a no-op (does nothing instead of closing the tab) would pass this test
  silently. Adding a follow-up `waitFor` on `tab-chip.*` count returning
  to `chipsBefore` would catch that class of regression.
- `app.windows.count` is sampled synchronously immediately after
  `typeKey("w", ...)`. `typeKey` awaits `Wait for co.sstools.Batty.beta
  to idle` before returning (visible in the test log), so the window-close
  path — if it were going to fire — would have completed. If a future
  refactor switches to a non-idling key dispatch path, this assertion would
  need a `waitFor`-based settle before sampling the window count.
