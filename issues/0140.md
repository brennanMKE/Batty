# 0140 — Title bar shows divider lines through themed window chrome

| | |
|---|---|
| **Status** | open |
| **Module** | Theme |
| **Platform** | macOS |
| **First seen** | 2026-05-19 |

## Description

When a theme is active, one or more faint lines are visible running through the title bar area, breaking the seamless window chrome appearance. This is a regression introduced during #0135 work (themed window chrome).

## Expected behavior

The title bar blends seamlessly with the sidebar and detail area — no divider lines or seams visible anywhere in the title bar region.

## Actual behavior

Faint vertical or horizontal lines appear through the title bar, coinciding with NSSplitView divider positions. The lines are most visible with dark themes.

## Notes

- Root cause is unresolved after seven fix rounds in #0135, experimentation in the Themes sandbox app (`../Themes`), and a Cursor-assisted debugging session. No fix found yet.
- The `WindowChromeApplier` in `RootWindowView.swift` sets `titlebarAppearsTransparent = true`, `backgroundColor = NSColor(bg)`, and `titlebarSeparatorStyle = .none`. The issue is that `NSSplitView` column dividers bleed through the transparent title bar.
- `softenSplitDividers` (walks the view tree setting `dividerStyle = .thin`) was one attempted mitigation — insufficient.
- Moving the themed background from inside the ZStack to a `.background(ignoresSafeAreaEdges: .all)` modifier on the ZStack (commit `625de37`) was the most recent approach; it eliminated one category of the problem but lines remain.
- The Themes sandbox (`../Themes/`) was built specifically to iterate on this without the overhead of the full app. See `../Themes/CLAUDE.md` and `../Themes/ThemeBug.md` for the running log of attempts.
- Deferred: living with the regression for now. Resume when a new approach is identified.
