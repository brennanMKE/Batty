## Description

An Xcode-style "Open Quickly" panel: press **Cmd-Shift-O**, type a few characters, see a fuzzy-matched list of named sessions and tabs across the current window, hit Return to jump straight to that session and tab. Xcode uses Cmd-Shift-O to match source files in a project; Batty's parallel is matching the navigable units of the multiplexer.

The killer use case: a dozen sessions are open, each with multiple tabs running different long-lived processes (`web`, `worker`, `db`, `tail-logs`, …). Cmd-Shift-O → `wor` → focus jumps to the right tab in the right session in one beat.

## Acceptance criteria

- Cmd-Shift-O from anywhere in the app opens a centered translucent sheet with a search field and a results list.
- The corpus searched is: every session name + every tab title in the current window. Result rows show `Session name › Tab title` (right-chevron separator), with the matched substring(s) highlighted in the row.
- Typing filters by case-insensitive fuzzy match (subsequence match, then ranked by tightness of match and recency of focus — recent-first feels right when the user is jumping back-and-forth between two areas).
- Up / Down arrow keys move selection; Return activates: brings the chosen session forward in the sidebar, focuses the chosen tab in its pane, and gives keyboard focus to the terminal. Esc dismisses without action.
- An empty query shows the most-recently-focused sessions/tabs ordered by recency — supports "Cmd-Shift-O, Return" as a quick toggle between two locations.
- Sessions and tabs with auto-derived titles (`#0089`) participate normally — what the sidebar / tab chip displays is what the panel searches against.

## Out of scope

- Searching panes by themselves (panes don't have user-facing names; tabs are the right granularity).
- Searching terminal content (scrollback). That's `Cmd-F`, a separate feature.
- Searching across multiple windows. Until multi-window lands (`#0027`), the corpus is the single window's content.
- Filtering by session-color tag or any other dimension. Pure name match for v1.
- Surfacing in-app commands. Those belong to the command palette (`#0126`); the two features are intentionally distinct entry points with distinct domains.

## Notes

- Xcode parallel: Cmd-Shift-O in Xcode matches *files in the project*. Batty's Cmd-Shift-O matches *places you can put your cursor*. Same keyboard shortcut, same fuzzy-find shape, different corpus.
- Related to `#0126` (command palette): both are fuzzy-find panels. Worth deciding whether they share a generic `FuzzyFinder<T>` SwiftUI component, or remain independent. Lean toward shared — the corpora differ but the row chrome, keyboard navigation, and highlight logic are identical.
- Fuzzy ranking: subsequence match is the table-stakes algorithm. For ranking, prefer contiguous matches over scattered ones (e.g. `wor` in "worker" beats `wor` in "wandering-orange"), then break ties by recency. A small Swift fuzzy-matcher (≈100 lines) is plenty — no need for an external dependency.
- Recency: track per-session and per-tab `lastFocusedAt: Date?` in the runtime store. Reset on every focus change.
- The bell feed (`#0027`) is the most-similar existing UI surface — popover with a list, click-to-jump. Match its visual style for consistency, but Open Quickly is a centered sheet (more prominent, keyboard-driven), not an anchored popover.
