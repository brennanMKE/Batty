## Description

Tier 3 localization target. Poland has a fast-growing developer community and a meaningful macOS install base.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `pl` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Polski shows the full UI translated.
- Visual sweep for string-length expansion (typically 15–25% longer than English; some technical terms longer).
- Plural variants in the catalog use Polish's three-form plural correctly — Polish distinguishes singular, "few" (2–4), and "many" (5+), all in the same grammatical category that English collapses. The String Catalog handles this when keys are declared with `.stringsdict`-style plural entries.
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Plural handling is the language-specific watch-out here. Make sure "Paste %lld lines" picks up all three forms via the catalog's plural rules — don't hand-write conditionals.
- Sparkle ships Polish strings.
