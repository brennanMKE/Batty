## Description

Tier 3 localization target. Poland has a fast-growing developer community and a meaningful macOS install base.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `pl` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to Polski shows the full UI translated.
- Visual sweep for string-length expansion (typically 15–25% longer than English; some technical terms longer).
- Plural variants in the catalog use Polish's three-form plural correctly — Polish distinguishes singular, "few" (2–4), and "many" (5+), all in the same grammatical category that English collapses. The String Catalog handles this when keys are declared with `.stringsdict`-style plural entries.
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Plural handling is the language-specific watch-out here. Make sure "Paste %lld lines" picks up all three forms via the catalog's plural rules — don't hand-write conditionals.
- Sparkle ships Polish strings.

## Root cause

Foundation issue `#0107` shipped `Batty/Localizable.xcstrings` with English source plus a handful of reference locales, but Polish (`pl`) had no `localizations` blocks. With Polish absent from the catalog, macOS in Polski falls back to the English source for every Batty-owned string.

## Fix

Populate `pl` for every key in `Batty/Localizable.xcstrings`:

- Simple keys: `Batty` (brand kept Latin), `Quit Batty?` → "Zakończyć Batty?", `Quit` → "Zakończ", `Cancel` → "Anuluj".
- Plural-aware keys carry all three Polish CLDR forms (`one`, `few`, `other`):
  - `Paste %lld lines?` → "Wkleić %lld linię? / linie? / linii?"
  - `There %lld open terminal(s).` → "Otwarty jest %lld terminal. / Otwarte są %lld terminale. / Otwartych jest %lld terminali."
  - `%lld unseen bell event(s)` → "%lld nieprzeczytane zdarzenie dzwonka / %lld nieprzeczytane zdarzenia dzwonka / %lld nieprzeczytanych zdarzeń dzwonka"

Button verbs follow Apple's macOS Polish conventions (Zakończ for Cmd-Q, Anuluj for cancel). `%lld` specifiers preserved verbatim. Native review pending.

## Files changed

- `Batty/Localizable.xcstrings` — adds the `pl` localization block (with `one`/`few`/`other` plural variants where applicable) to all 7 catalog keys.

## Gotchas

- Translations are LLM-authored. A native-speaker pass is still owed before the Polish UI is "final"; the per-language tier-3 acceptance criterion calls for that review.
- Polish CLDR has three plural categories used here: `one` (n=1), `few` (n=2-4 except 12-14, etc.), `other` (everything else including 0, 5-21, 11-14, 25+). The catalog deliberately uses all three; do not fold `few` into `other` even though English does.
- Polish strings expand 15-25% versus English (e.g. "Otwartych jest %lld terminali." is wordier than "There are %lld open terminals."). Watch fixed-width buttons and toolbar labels during a visual sweep.
- Sparkle's own UI ships its own Polish strings — no work needed in this issue.
