## Description

Tier 2 localization target. South Korea has a strong tech ecosystem and a meaningful macOS developer population. Batty's existing CJK IME work serves Korean Hangul input on the terminal side; localizing the UI completes the experience.

Depends on `#0107`.

## Acceptance criteria

- Every key in `Localizable.xcstrings` has a non-empty `ko` translation, reviewed by a native speaker.
- Launching with macOS Language & Region set to 한국어 shows the full UI translated.
- Visual sweep confirms Hangul renders cleanly in Settings labels, menu items, and alerts.
- `## Files changed` should list the `.xcstrings` diff.

## Notes

- Hangul tends to be slightly more compact than English horizontally — clipping risk is lower than in German or French, but verify anyway.
- Product name "Batty" stays in Latin script.
- Bell feed timestamps render in Korean format via the system locale automatically.
- Sparkle ships Korean strings.
