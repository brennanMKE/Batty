## Description

The Xcode project has a third build configuration called "Beta Debug" on every target (Batty, BattyTests, BattyUITests) and at the project level. The reference project (`../BetaProd`) demonstrates the correct pattern: **only Debug and Release configurations exist**. The Beta/Prod distinction is injected entirely at build time by `scripts/set-environment.sh`, which writes `Configuration/Active.xcconfig`. A separate build configuration is the wrong mechanism and duplicates the project unnecessarily.

## Root cause

Commit `2db8cbc Add Beta Debug build configuration to fix scheme launch failure` added "Beta Debug" as a workaround when the Beta scheme failed to launch. The actual launch failure was caused by `BuildableName = "Batty Beta.app"` not matching the built product (a separate issue now fixed in #0218), not by a missing configuration. Rather than fixing the `BuildableName` mismatch, a whole new configuration was added.

"Beta Debug" also introduced `AppBeta.xcconfig`, which `#include`s both `App.xcconfig` and `Beta.xcconfig` directly — bypassing the `Active.xcconfig` mechanism entirely and hard-wiring the Beta variant into a named configuration. This is the opposite of the `../BetaProd` design.

## What the reference project shows

`../BetaProd` has exactly two configurations: `Debug` and `Release`. Both `BetaProd (Beta)` and `BetaProd (Prod)` schemes set `buildConfiguration = "Debug"` for TestAction / LaunchAction / AnalyzeAction and `buildConfiguration = "Release"` for ProfileAction / ArchiveAction. The pre-action script runs `set-environment.sh Beta` (or `Prod`), writing `Active.xcconfig`, which is `#include?`'d at the bottom of the base xcconfig. The build then picks up the variant settings through that chain.

Batty's `App.xcconfig` already does `#include? "Active.xcconfig"` — the mechanism is in place. The `Debug` configuration for the Batty target already uses `App.xcconfig` as its base. Everything required for the correct pattern already exists.

## Fix

1. Remove "Beta Debug" `XCBuildConfiguration` from all four configuration lists in `project.pbxproj` (project level, Batty, BattyTests, BattyUITests).
2. Remove the `AppBeta.xcconfig` file reference from `project.pbxproj` and delete the file.
3. Update `Batty (Beta).xcscheme`: change `buildConfiguration = "Beta Debug"` to `buildConfiguration = "Debug"` in TestAction, LaunchAction, and AnalyzeAction (ProfileAction and ArchiveAction stay on Release).

## Files changed

- `Batty.xcodeproj/project.pbxproj` — removed 4 "Beta Debug" `XCBuildConfiguration` objects and their entries from all 4 `XCConfigurationList` arrays; removed `AppBeta.xcconfig` file reference
- `Configuration/AppBeta.xcconfig` — deleted
- `Batty.xcodeproj/xcshareddata/xcschemes/Batty (Beta).xcscheme` — changed TestAction, LaunchAction, AnalyzeAction from `buildConfiguration = "Beta Debug"` to `buildConfiguration = "Debug"`
