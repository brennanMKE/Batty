## Description

Child of #0689. User decision E (2026-11-19): "replace the in-app NWListener static server (#0649) with the PhotonHTTP Swift package (SPM dependency in BattyKit/Package.swift). Batty's static server exposes a standard minimal REST API for status and stats (e.g. GET /_batty/status → JSON) that the servers list reads; CLI stop/restart. Keep 127.0.0.1 binding; tailnet exposure is via tailscale serve."

### Current state (checked against `main` at `94b038c1`)

- `BattyKit/Sources/BattyKit/Runtime/StaticServer/` — 10 files (~860 lines): `StaticFileServer` (`NWListener`, `127.0.0.1` only, `StaticServing` protocol with `start(port:)`, `stop()`, `waitUntilStopped()`, `broadcastReload()`, `stats` = request and reload-client counts), path resolver, MIME types, byte ranges, directory listing, `ReloadScriptInjector` + `StaticReloadBroadcaster` (server-sent events for reload on change), `DirectoryChangeWatcher`. Wrapped by `InAppStaticServerBackend`; tests `StaticFileServerTests`, `InAppStaticServerTests`.

### PhotonHTTP (`github.com/brennanMKE/PhotonHTTP`, read 2026-11-19 at `6c9c1686`)

- Package name `SwiftWebServer`; `swift-tools-version: 6.4`; `platforms: [.macOS(.v15)]`; Swift 6 language mode; **no package dependencies**; uses package traits (`HTTP2`, `HTTP3`, default on, affecting only the executable).
- **No LICENSE file**, no tags or releases; README says macOS 15+ only, BSD sockets/kqueue/`sendfile` plus Network.framework for TLS/QUIC, binds `127.0.0.1` by default.
- Library products relevant here: `HTTPCore`, `HTTP1`, `HTTPServer` (`Server(listeners:protocols:) { middleware… }`, `run()`, `waitUntilRunning() -> [TransportAddress]`, `requestShutdown()`, `shutdown()`, `restart(…)`, counters `openConnectionCount`, `acceptedConnectionCount`, `peakConnectionCount`, `listenerStatistics`), `NetworkTransport` (`BSDSocketListener`), `StaticFiles` (`StaticFiles(root:configuration:)` handler/middleware: index files, MIME, ETags, conditional requests, single Range, dotfile/traversal protection, `StaticFilesConfiguration`), `Router` (in-process routes), `AccessLog` (`AccessLogMetrics`, `MetricsEndpoint` serving Prometheus text at `/metrics`). Response bodies support `.stream(length:writer:)`, enough for server-sent events.

## Expected behavior

- Add PhotonHTTP to `BattyKit/Package.swift` pinned by **revision** (as libghostty-spm is), linking only the products above that Batty uses. If SwiftPM requires the root's tools version to be ≥ 6.4 for a 6.4 dependency, bump BattyKit's after checking Xcode 27 and the VM golden support it.
- Reimplement `StaticServing` on PhotonHTTP: `Server` with a `BSDSocketListener` bound to `127.0.0.1` (port 0 = ephemeral, as today), middleware chain = Batty status route → reload SSE route + reload-script injection → `StaticFiles`. Delete the replaced `StaticServer/` files; keep `DirectoryChangeWatcher` and the reload behavior.
- **Status API:** `GET /_batty/status` → `application/json`: `{ "name", "root", "port", "startedAt", "uptimeSeconds", "requests", "openConnections", "acceptedConnections", "reloadClients", "version" }` (field set confirmed in the plan; stable, documented in `docs/batty-cli-design.md`). Only `GET`/`HEAD`; reserved prefix `/_batty/` is never served from the folder. The Servers list (#0691) reads it for `static` entries; `server list --json` (#0692) includes it.
- `batty server serve <dir> [--port N] [--open]` runs on PhotonHTTP and registers as `static` kind; `server stop`/`restart` (#0692) stop or restart it (`shutdown()` then a new `Server`, or `restart`).
- Starts only on request (`serve`); nothing listens at launch.

## Acceptance criteria

1. Before implementation, PhotonHTTP has a LICENSE the user chose, and the pinned revision is recorded here; `Batty/Batty.entitlements`/notarization unaffected.
2. Unit tests (no sleeps; await `waitUntilRunning()` and real requests over loopback, off the main actor): serves index and files with correct MIME; 404 for traversal and dotfiles; `/_batty/status` JSON decodes with the expected fields and counts a request; binds `127.0.0.1` only (connecting to the machine's LAN address fails); stop frees the port; reload SSE delivers an event on file change through the injected watcher.
3. `./build.sh`, `./build.sh unit` (timings noted against #0592's budget) and the Release archive (`./build.sh release archive …`, per AGENTS.md for new generic-heavy dependencies) pass.
4. A fresh install shows nothing new and opens no listening socket until `server serve` runs.

## Decisions (user, 2026-11-19)

- **License:** PhotonHTTP (`github.com/brennanMKE/PhotonHTTP`) now has an MIT license (GitHub reports spdx `MIT`, pushed 2026-11-19).
- **Rename:** the user is renaming the package from `SwiftWebServer` to `PhotonHTTP`. The implementer uses the new package and product names.
- **Pinning:** PhotonHTTP has no tags yet. Pin a version tag created after the rename; if none exists when implementing, ask the user for the tag. Never pin a branch.
